# 手动续费的服务器工作区

财务、管理员和超级管理员可以在「手动充值」管理本人的地址和续费记录，普通员工没有此权限。管理站校验平台会话和记录归属，从操作员 ID 与记录 ID 产生固定工作区键。已登录的另一台电脑或手机可以用同一条记录重新连接。每个工作区包含一个普通 Chromium 和一个私有显示服务。首次启动打开 ChatGPT 官网，由操作员自行登录。再次启动由 Chromium 从该工作区的资料卷恢复标签和有效登录。

同一个平台账号同时只能运行一条续费记录的工作区。电脑或手机再次连接这条记录时复用原工作区。只断开画面时，服务器继续运行该工作区并保留名额。要换另一条记录，请先「保存并关闭工作区」。保存多条续费记录不占运行名额。不同操作员分别计算，整机可承载的数量仍受资源门槛控制。

## 网站、连接服务与浏览器

- 网站通过 `ID_MANUAL_WORKSPACE_SOCKET` 连接私有 Unix 套接字。该变量为空时，续费记录维持原有操作。配置生效后，可在「账号续费管理 → 查看记录 → 打开服务器工作区」进入桌面。工作区页打开时需点击「连接工作区」。
- 网站对工作区请求发送已核准的工作区键和从登录身份计算的操作员标识。平台 Cookie 留在网站。连接服务在 Linux 上使用 Python 3 和 aiohttp，从管理员只读安装的 noVNC 目录提供浏览器端模块。浏览器网页内容仅通过远程画面显示。挂载结构见 [工作区进程说明](worker/README.md)。
- 连接服务通过 `<workers>/<key>/rfb.sock` 接收单个工作区的画面和输入。Linux 按文件描述符固定实际套接字，拒绝软链接。连接服务只需读取各工作区的套接字目录和受信任的 noVNC 资源；网站容器只需访问连接服务的套接字。
- 每个浏览器进程只挂载自己的资料卷与临时显示目录。「断开连接」保留运行中的网页。「保存并关闭工作区」让 Chromium 正常写盘，关闭该账号的桌面并释放内存。连接服务等待正常退出、成功的服务状态和显示套接字关闭后才确认完成。下次打开同一资料卷时恢复上次的标签。第三方网站决定登录到期时间。续费记录里的历史代理字段不参与启动。

## 隔离环境验证

使用未连接业务网络的 Linux 测试环境和虚构账号。将 `broker.py` 与发行版安装的 `python3-aiohttp`、可信 noVNC 模块放在连接端，安装 Chromium、TigerVNC 的步骤见 worker 目录。只把测试服务的套接字目录提供给测试网站。

连接服务的基础命令为 `python3 broker.py --socket /run/id-bridge/site.sock --workers /run/id-ws --claims /var/lib/id-manual-broker/claims --assets /usr/share/novnc`。此模式仅接续已有归属的运行中工作区。首次启动工作区需按下节启用服务单元。操作员占用记录存放在归连接服务独占、权限 0700 的持久目录。网站和工作区均不挂载该目录。套接字父目录归连接服务所有，禁止组或其他用户写入；套接字 0660 的组仅分配给获准连接的网站。服务不监听公网端口。两个独立浏览器客户端应使用各自的平台登录会话，分别验证在运行的桌面接续、正常关闭后恢复和其他账号资料隔离。

工作区启停依赖宿主配置的 `id-manual-workspace@<key>.service`。只有该服务可以分配资料卷和在隔离环境内启动工作区。给连接服务的启停权限限定到该模板。启用 `--start-units` 时同时指定 `--max-active` 和 `--min-available-mib`，数值应来自对应主机的并发与业务余量实测。达到上限时新开桌面返回繁忙，已运行桌面仍可接续。单元及服务组的硬资源上限由宿主执行。

运行 `python3 -B deploy/manual-desktop/test_broker.py -v` 检查连接转发、资源准入、资料分离与资源路径。套接字软链接检查需要 Linux。网站路由和权限覆盖在 `test/manual-remote-access.test.mjs`。两个独立平台登录、操作者归属、注销后的断连由 `test/manual-remote-access.integration.test.mjs` 验证。

在隔离测试机运行 `node --test test/manual-renewal-roles.integration.mjs`，使用测试身份登录网站，检查财务和管理员的本人续费记录、地址、套餐汇总与工作区权限，以及普通员工的拒绝结果。

[Linux 图形验收](../../test/manual-remote-desktop-linux/run.sh) 在一次性测试机安装临时服务单元，通过两个客户端的可见画面验证账号隔离、操作接续及关闭重开。测试仅使用虚构的登录资料，完成后回收临时单元。资源读数来自工作区所在的 cgroup。

## 正式启用条件

本目录随源码提供。启用前需要在目标宿主核验 Chromium 沙箱、资料卷隔离、对宿主及内部服务的网络阻断、可用内存和额外出站流量。测试网的轻量网页无法代表实际网站的资源峰值。正式接入沿用网站的统一发布入口及回滚。停用网站接入时移除其套接字配置，保留工作区资料卷。
