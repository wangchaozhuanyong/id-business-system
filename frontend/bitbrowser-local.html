比特浏览器直连说明

  1. 在当前电脑启动并登录比特浏览器。进入「系统设置 → Local API（本地接口）」启用接口和鉴权，子账号需要接口权限。
  2. 为每台电脑或每个比特账号分别新增并命名配置。填写该电脑显示的本机接口地址和密钥，浏览器询问本地或回环网络访问权限时选择允许。
  3. 检测连接，选择读取到的窗口分组和标签，再保存配置。切换电脑后选择对应配置并重新检测。

登录业务系统后，保存连接会加密保存本机接口密钥。切换到已保存的连接时会自动读取密钥并检测。执行 IP 从个人 IP 列表单独选择，链接加密保存，国家和类型随 IP 读取。已开始的登录会使用启动时的连接配置。

先在当前电脑的比特客户端登录对应主账号或子账号，再选该连接。网站不会切换客户端登录账号；新电脑首次需配置自己的接口密钥。

录入 IP 时标记国家与类型，执行时直接选择 IP。
