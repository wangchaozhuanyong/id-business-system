# 比特浏览器授权 JSON 登录

独立新版沿用旧版固定提交 `e51dd9c9974c6292dbbc6572a5d844a672f0d0f1` 的「仅登录账号 → 授权 JSON」分支。先粘贴 JSON 或导入 JSON/TXT，再在比特连接设置填写本机接口密钥、检测连接并选择窗口分组和标签，最后点击「登录账号」。若提示需要验证，请在已打开的比特窗口完成。

登录执行器在 [login](login/README.md)。它直连本机比特及其浏览器控制通道，核验官网邮箱、用户 ID 和账号 ID 后显示登录成功并保留窗口。授权只在当前浏览器页面内存中处理，独立新版预览服务器不接收授权。已核验归属的窗口仅在本页面存续期间可重用。测试使用本机模拟比特接口和浏览器控制通道。

本机业务版的「新增比特连接」可按电脑或比特账号命名，保存回环接口地址、分组和标签、内核、非凭据代理设置及等待和重试次数。登录业务系统后，接口密钥随配置按操作账号加密保存。选择配置时自动读取该条密钥并检测分组与标签，同一标签页刷新后恢复最后选中的配置。已有配置可填入密钥、检测后重新保存。代理凭据和授权 JSON 在当前页面内存使用。直连请求由当前电脑的浏览器发出。

本机业务模式下，管理员可从比特登录页打开「地址管理」。一键生成默认 10 条，每次可选 1 至 100 条，沿用线上地址管理的美国城市、州、邮编组合和街道生成规则。生成并保存地址后刷新列表。原 TXT 导入固定使用美国 Portland、OR、97204，每批 1 至 2000 行，导入会报告新增、重复和无效行数。地址按当前操作账号保存在独立新版的本机库，生成和审计同事务提交。支持搜索、状态筛选、分页、列设置和逐条复制完整地址。复制不会改变状态，实际用过后可手动标记，已使用地址不能恢复。

在 [本机比特登录页](http://127.0.0.1:4348/#/recharge/start) 体验。运行和验证使用本目录的独立新版实现。
