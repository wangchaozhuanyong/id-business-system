# 邮箱池服务商识别发布

本窗口明确授权两个独立项目正式发布。本对象只发布 ID 系统已审查的四个邮箱录入文件；新增发布控制用于把本次 Admin 源码覆盖到已经验证的当前原生源码，不携带 main 中其他尚未上线的功能。

当前前版固定为 `7c5ddc35e15aeecbf54f71acce96498c38b73d45`。已通过现有前版生产验证器独立只读回读，并捕获七服务的实际镜像、容器、启动、环境与配置指纹。首次读取超过 SSM 单条输出边界，改用项目内专属观察回执与两个带整体 SHA256 的有界片段读取；没有放宽身份或内容校验。

发布使用 `Mailbox Provider Publication`，填写远端当前 main 完整 SHA 和上述实际前版。必须通过本次 PR 的精确源码树 Quality Gate 和同 SHA 的 main Quality Gate；前版或 main 变化立即拒绝。

构建先从既有生产来源复现当前 Admin、API 和执行器输入，并与已发布原生证明逐文件比对；之后只覆盖三个生产 UI 文件重新构建 Admin。第四个文件是已由本次质量检查执行的合成回归测试，随源码证明保存。发布制品不得包含 API、执行器、环境文件或其他来源覆盖；只更新 Admin，完整保留其余六服务。新制品、提交、源码树与本次运行一一绑定，不复用旧页面构建产物。

生产切换沿用现有部署锁、指纹校验、活动任务保护、只读门禁和原生镜像校验；切换前生成新鲜并核验 S3 的范围备份。没有数据库迁移、付款、通知、账号授权或其他业务写入。失败保留现场和向前诊断回执，不擅自执行生产回滚。

功能验证包括 Outlook/Hotmail 自动分流、误选复核、失败保留输入、Gmail/iCloud 原流程、企业域名手动选择和批量密码列保护。线上只输入合成地址核对服务商及授权方式，不提交、不完成 OAuth、不创建邮箱记录；手机尺寸与桌面分别验收。
