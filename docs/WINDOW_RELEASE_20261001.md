# 本窗口统一发布（2026-10-01）

## 已完成并纳入的范围

1. Pro 500 美元档接入本机与服务器执行器：官网档位识别、独立建单标识和订阅核验；自动充值菜单移除 Business、Enterprise、Edu，手工订单与历史目录保留。
2. 便捷操作改为两行摘要、抽屉内全文阅读和独立滚动，复制只带正文；保留 main 已发布的拖拽排序。
3. 新增功能关闭抽屉或切换导航保留同一标签页、同一身份的草稿，成功保存才清理对应内容；身份变化、刷新时清理，安全码、临时验证码与单次付款确认不保留。
4. 地址库数据就绪后按既有可用状态与使用时间规则自动选择，优先已保存银行卡核实地址；允许下拉手动改选，刷新和导航不覆盖有效选择。
5. 服务器复用当前用户系统 2FA 配置，后端核对归属并审计，执行器按需生成、自动填写；原订单只读复查不付款。
6. 代理国家与账单国家独立，菲律宾等代理可使用美国账单地址；代理出口仍须匹配所选代理国家，付款资料和金额校验保持。
7. ChatGPT 单条新增与批量导入不强制密码，默认邮箱加 2FA，保留含密码格式；实际密码登录仍需密码。
8. ChatGPT 账号操作增加复制，按 `邮箱-密码-2FA密钥-当前有效BUY查询码` 输出；虚拟邮箱管理批量导入左侧增加当前管理员的多行复制后缀设置。
9. 导入整批选择所属主邮箱，仅一个正常主邮箱时自动选中；先校验，再复用已有隐藏邮箱、添加缺失项并读回确认，最后原子保存本地账号。冲突或失败保留草稿供重试，不重置已有查询码。

## 接口和数据

- 新增 GET／PUT `/id-business-v2/bank-recharge/account-copy-settings` 和 POST `/id-business-v2/bank-recharge/accounts/:id/copy`；准确路由以控制器为准。
- 既有账号导入支持可选 `primaryAccountId`，界面要求整批选择主邮箱；启动和只读复查支持可选 `login.totpAccountId`。
- 复制后缀复用现有浏览器设置 JSON 内部键 `accountCopySuffix`，不传执行器。
- 无新增数据库模型、字段、migration、依赖或环境变量。无真实付款、测试账号导入或生产业务数据写入。
