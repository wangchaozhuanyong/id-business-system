# 页面布局统一收尾

汇总“改为单行布局”窗口的六组已完成改动，以已发布 main 为基础合并。

| 用户反馈                             | 交付                                                             |
| ------------------------------------ | ---------------------------------------------------------------- |
| 地址导入与搜索占两块                 | 共用 V2ListToolbar，宽屏 62px，长文件名省略，窄屏换行            |
| 邮箱页顶部过高                       | 说明／状态一行，页签／筛选／操作一行，保留业务入口               |
| 代理、银行卡、ChatGPT 账号标签不统一 | 公共 filters／actions，说明收进帮助入口                          |
| 订单、客户筛选与客户长说明           | 标题、筛选、操作、数量同行，客户总览约 82px                      |
| 新页面对齐与模块间距反复分叉         | 21 个总览、15 个筛选组件接入公共实现，统一根布局与间距，增加门禁 |
| 末页／空状态列表缩小                 | 观察异步出现或替换的列表体，保留最大稳定高度                     |

整合时补齐公共表单尺寸、旧标签覆盖和手机端订单录入。地址筛选／分页参数变化没有触发读取，在 useV2ModuleQuery 统一补上监听，并验证读取失败保留已有内容。

线上验收发现少量客户的首屏仍低于空状态的固有高度。公共 records 列表现在预留桌面表头与空状态的最低高度，手机卡片预留空状态高度，再叠加已记忆的内容高度。手机卡片模式同时隐藏整个桌面表格外壳，避免外壳的保高值重复占位；新增 1／2 条客户、双主题、桌面／手机切换为空和恢复的 8 个回归场景，避免只测满页遗漏该情况。

## 范围

仅前端、布局检查、夹具及规范。其他窗口的输入保留、皮肤改版、Google Drive／Sheets 同步、自动充值业务和后端未发布修改均保留。已发布财务及订阅功能沿用 main。

无新增接口、表、字段、迁移或依赖。本地浏览器使用合成资料与拦截响应，真实业务写入为 0。

## 验证

- 管理端 123 个文件、630 项测试；控制检查 30 项。
- 双主题共享布局 176 项，9 个视口筛选与实际路由回归 274 项，含 8 个短列表空状态与手机重复占位检查。
- 地址 40 项、邮箱 56 项、客户实际路由 16 项；客户覆盖首末页、空状态、刷新、失败重试、权限与窄屏。
- 类型／构建、定向 lint／格式、中文／UI／主题／表格／加载／架构／隔离／Element Plus 检查通过。
- CI 按 admin 范围执行，并运行两个布局回归；生产发布只更新 Admin 镜像，不执行数据库迁移。

合并、远端 CI、生产运行 SHA、公开健康与登录后页面验收分别核对。发布记录保存在本项目 `.runtime/window-layout-release-20261002/`。
