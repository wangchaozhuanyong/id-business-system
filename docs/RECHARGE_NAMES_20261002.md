# 姓名库与开通银行卡

本任务归属 ID 业务管理系统，基于 `c59861de03df8b71d5dc3442951d82ee859d4d97`。
只完成本地开发与验证，未提交、推送或部署。

## 行为

- 自动充值分组新增“姓名库”：录入、批量去重、编辑、启用／停用、完整姓名搜索与分页。
- 新卡按匹配次数升序、录入序号升序分配启用姓名。首次顺序使用，全部使用后从头循环；同一卡号重复输入不会推进顺序。匹配次数表示分配次数，不代表付款成功次数。
- 优先回填完整卡号的历史绑定姓名；新卡姓名可在付款前按实际资料修正，成功后确认绑定。改名、停用姓名条目或删除卡资料不改历史姓名。
- 银行卡清单、详情和表单增加持卡人姓名。账号清单新增“银行卡信息”和“银行卡删除状态”：最近成功开通的实际银行卡显示开头 1 位和末尾 8 位，中间以星号隐藏；删除前显示“尚未删除”，删除后显示“已删除”。尚未开通或缺少真实卡资料时显示“未记录”。
- 删除银行卡先显示共享账号／订单数量，提交时核对卡版本、最新开通单和影响范围；未结束任务阻止删除。卡资料删除后，账号、订阅、订单、任务和财务保留，卡外键置空，订单保留名称／脱敏卡号快照和删除时间。“删除卡”按钮删除银行卡资料表中对应的整张卡，共享此卡的账号也同步标记已删除。
- 匹配、导入、修改、登记和删除都按管理员权限执行并写审计。审计不含完整卡号；姓名加密存储，历史卡姓名表只保存卡号盲索引和加密姓名。
- 本机任务启动只新增 `cardId`／`billingName`，完整卡号通过独立卡登记接口加密保存；安全码、登录密码、临时 2FA 和付款授权的既有边界保持不变。

## 接口

所有路径位于 `/api/id-business-v2`，仅管理员可用。

| 方法   | 路径                                                | 用途                             |
| ------ | --------------------------------------------------- | -------------------------------- |
| GET    | `/auto-recharge/names`                              | 姓名分页、完整姓名搜索、状态筛选 |
| POST   | `/auto-recharge/names/import`                       | 每次 1 至 2000 个姓名，去重导入  |
| PATCH  | `/auto-recharge/names/:id`                          | 编辑／停用，携带原始更新时间     |
| POST   | `/auto-recharge/names/match`                        | 使用完整卡号匹配或回填姓名       |
| POST   | `/auto-recharge/names/payment-card`                 | 本机启动前登记卡，返回卡编号     |
| GET    | `/bank-recharge/accounts/:id/opening-card-deletion` | 删除影响预览                     |
| DELETE | `/bank-recharge/accounts/:id/opening-card`          | 带预览编号、数量和版本删除卡资料 |

银行卡新增／编辑接口新增可选 `billingName`；账号列表新增 `openingCard`（`numberSummary` 为脱敏卡号，`deleted` 为删除状态）；本机任务启动增加可选卡编号及姓名。没有新增依赖或环境变量。
