# 线上代充代理国家独立发布

用户要求线上代充可选择代理国家，多国代理共存时不能跨国家随机选择，随后明确授权单独发布。

候选从最新 `main@69eba563895bf083b24c8214a088454d5df34922` 隔离提取，只叠加国家配置、任务快照、代理查询及相关测试。
保留当前已发布订单同步、Pro 500、代理检测终态和注册草稿修复；不复制旧主目录的完整业务文件。

系统配置增加“代理国家”，与支付地区独立。新业务任务在受理前检查国家和启用代理，在任务 JSON 保存国家快照；
执行时同时按指定国家、启用状态和指定代理编号筛选。同国多条可轮换，无可用代理或未配置时停止，不跨国回退。
没有快照的历史任务首次取代理时采用已保存国家，独立代理检测仍可检测任意国家。

没有新增数据库表、列、迁移、依赖或环境变量。原配置 JSON 和任务 payload 增加 `proxyCountryCode`。
上线后须先选择代理国家，才能创建新业务任务；本次发布不替用户修改支付地区或启动充值。

生产只更新 API 与 Admin，线上代充执行器以同一镜像重连新 API 网络；自动充值、自动注册、MySQL、媒体及 Caddy 保持。
发布前核验当前清单、镜像、完整配置摘要、任务空闲、空间和备份，发布后独立回读及真实页面验收。
真实代理请求、付款、订阅变更、第三方建单和外部通知不在本次发布验收内。

原主目录本地验证：65 项定向测试、构建／类型／lint／七项规则以及 12 组离线页面验收通过。
隔离候选接入较新订单同步构造参数后，当前 API / 代理池 110 项单测通过；远端空 MySQL 验证与 Linux 构建由只读权限 CI 单独执行。
候选、PR、CI、镜像、切换及页面验收结果分别记录于本工作树 `.runtime/online-proxy-country-release-20261016/`，未取得回执前不宣称上线。

首次远端 Quality Gate 的发布入口与维护保护通过，执行器回归因测试固定旧 API 源码指纹而失败。
修正当前源码的测试绑定，保留历史镜像夹具原编译指纹；历史注册恢复测试读取其已发布源码，并继续拒绝当前新源码。
有限 CI 入口只接纳本功能的明确文件，保留格式、lint、选择器、七项 UI 规则、后端架构、API 单测／类型／构建、管理端单测／构建／离线页面及执行器全套测试。
任何额外数据库、依赖、镜像配置或执行器业务文件仍回到原检查，不放行历史封装镜像为本次发布候选；生产执行器镜像继续保持原版本。

34 项独立 MySQL 验证通过。切换前另一个已合入的注册功能尚未发布，因此管理端构建允许指定经回读确认的线上 Admin 提交，
仅叠加本功能的两个配置文件，并用真实 Git 树和文件摘要记录来源；发布准备会核对该基线与线上一致，避免带入未发布页面。
API 编译产物除本功能 7 个模块外，577 个 JavaScript 文件与当前生产完全一致；更新仍仅复制这 7 个模块。
