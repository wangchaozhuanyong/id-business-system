# 邮箱池逐行列表与服务商说明

范围：独立新版的邮箱查询与管理右侧抽屉。用户要求一个邮箱一行，适应数百、数千条记录，并补回登记邮箱所需的设置地址和说明。

## 页面行为

- 两列账号卡片改为紧凑表格，一个账号一行。六列为邮箱与备注、查询码及复制、状态、到期时间、最近查询、操作。查询码单行省略，复制按钮只显示“复制”并与查询码同排；实际复制完整值。
- 默认每页 20 条，可选择 50／100 条，显示总数与当前区间，支持上一页、下一页和输入页码跳转。搜索和筛选回到第一页，关闭重开保留页码、每页条数和已有草稿。
- 分页区滚动时保留在正文顶部。手机表格内部横向滑动，并显示滑动提示；展开操作按钮完整保留，不改变原有停用、授权、重置查询码的确认与执行流程。
- 邮箱第一行、类型和备注第二行，长邮箱和备注省略并保留悬停全文；每条记录最多两行。更多操作使用顶层浮层，不再撑高数据行。页面只渲染当前页，只读取当前页查询码。仍沿用既有接口读取邮箱元数据后在前端分页，没有增加服务端分页接口或数据库迁移。
- 邮箱池标题说明补回三个服务商的办理入口；单个登记与批量导入均随服务商显示对应指南。更新授权表单打开后滚入可见范围。

## 官方设置地址

- Google：`https://myaccount.google.com/apppasswords`；先启用两步验证，再生成应用专用密码。[Google 官方说明](https://support.google.com/accounts/answer/185833?hl=zh-Hans)
- Apple：`https://account.apple.com/`；登录和安全 → App 专用密码。[Apple 官方说明](https://support.apple.com/zh-cn/102654)
- Microsoft：`https://account.microsoft.com/` 用于账号管理；本系统登记用“连接 Microsoft 并添加”，批量导入点击保存后逐个授权，已有记录使用“重新授权”。不将账户主页误作本系统授权地址。[Microsoft 账户登录说明](https://support.microsoft.com/en-us/accounts-billing/manage/how-to-sign-in-to-a-microsoft-account)

## 最新修订：每条记录最多两行

用户进一步要求缩短数据行，不再完整铺开长查询码。本轮改动限定于 `frontend/operations-prototype.js`、`frontend/prototype.css`、原有邮箱池专项浏览器测试及相关说明文档。

- 状态、到期时间、最近查询各占一列；邮箱与类型／备注最多两行，其他单元格单行显示。
- 长邮箱、备注和查询码使用省略号；悬停可看完整值。“复制”只复制完整查询码，不复制省略后的文字。
- 更多操作改为原生顶层浮层，打开、关闭、滚动及触屏操作均不增加表格行高；原有操作、分页与服务商说明保留。
