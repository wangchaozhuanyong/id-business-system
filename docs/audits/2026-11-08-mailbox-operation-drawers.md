# 邮箱池行操作右侧抽屉

2026-11-08。状态：代码完成、本地离线验证完成；未提交、推送、部署或修改线上资料。

## 页面设计与交互

邮箱池列表保留原有表格。“更多操作”直接展开功能菜单，点击具体功能进入共享右侧抽屉，不增加选择操作的中转页。

| 入口 | 抽屉内容 |
| --- | --- |
| 查询 | 当前邮箱、服务商及状态；返回封数、查询按钮、刷新和邮件结果。按行查询直接读取该邮箱，无须再次填写查询码。 |
| 去授权／更新授权 | 当前邮箱摘要、应用专用密码及说明；底部取消、验证保存。Microsoft 在抽屉中发起原有外部只读授权窗口，并在抽屉内核对回执。 |
| 隐藏邮箱去授权 | 显示所属主邮箱授权说明，由用户主动打开隐藏邮箱管理。 |
| 重置查询码 | 当前邮箱、有效期、旧码失效提示；保存后在抽屉内交付新码及复制入口。 |
| 启用／停用 | 当前邮箱和影响说明；点击确认按钮后才提交变更，成功后显示最新状态。 |

抽屉顶部使用紧凑邮箱摘要，长邮箱可换行。表单沿用左侧标签、必填标记与标题说明按钮；授权、重置和状态操作使用固定底部按钮。查询按钮与查询条件同排，邮件结果独立呈现。浅色、深色及窄屏均沿用现有主题和共享抽屉。

关闭后保留列表筛选、分页和滚动位置；普通输入继续通过现有会话草稿保存，应用专用密码、查询码和邮件正文不进入草稿，关闭时清除本次临时内容。关闭后立即切页不会自动重开旧编辑表单；迟到的查询、OAuth 发起或完成响应不能覆盖其他抽屉。

已有“在线工具”入口本身就在右侧抽屉内，继续使用原内部页面，不嵌套或销毁父抽屉。登记邮箱、批量导入和全局查询码设置的原入口保留。

## 本轮文件

- `frontend/operations-prototype.js`：复用共享抽屉、已有表单、查询及保存接口，补充抽屉生命周期和异步响应归属保护。
- `frontend/prototype.css`：邮箱摘要与元信息样式；将现有查询按钮、结果标题规则扩展至邮箱操作抽屉变体。
- `test/mailbox-operation-drawers.browser.mjs`：新增行操作、失败重试、普通草稿、敏感内容清理、迟到响应、旧在线工具入口及响应式回归。
- `test/mailbox-pool-layout.browser.mjs`：更新授权抽屉断言，验证最后一页打开／关闭操作后分页和滚动不变；说明链接按实际点击展开流程检查。
- `test/plugin-management.browser.mjs`：授权固定底部按钮、关闭后继续查询及邮件链接回归。

前序邮箱匹配隔离、租户归属和产品币种设置的未提交修改均保留。没有新增 HTTP 接口、数据库表、字段或迁移。
