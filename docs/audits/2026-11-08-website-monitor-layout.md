# 网站监控三页签布局整理

2026-11-08。状态：代码完成、本地离线验证完成；未提交、推送、部署或修改线上资料。

## 布局方案与实际修改

三个页签统一使用“导航 → 标题及操作 → 筛选／输入 → 结果”的结构，沿用原有品牌、控件、主题及业务功能。

- **访问统计**：时间范围、刷新和完整报表入口归到标题操作区；浏览量、访客数、会话数置于同一指标带；报表原始时区保持可见，数值列统一右对齐。
- **访问记录与 IP**：刷新、查询入口放到标题右侧；四个筛选在宽屏均匀一行，中等宽度两列、手机单列；概览、每日统计／IP 明细、表格和分页按统一间距排列。
- **网站检测**：标题与检测按钮同一操作区，地址输入独立一行，检测结果在下方展示；移除原表单页脚的额外横线及留白。

共用 `websiteToolHeader()`、`websiteMetrics()` 和共享样式，避免三个页签分别修补边距。导航底线与内容相距 20px。标题字体、行高和垂直居中模型一致；按钮与输入、导航边界不重叠。原“在线工具”抽屉中的网站监控同步使用这套布局。

实际文字测量：1440px 三页标题均为 x=277、y=176.75；1024px 均为 x=265、y=176.75；390px 和 320px 均为 x=33、y=222.75。筛选列数依次为 4／2／1／1，深浅主题一致。
