# ID 业务页面验收矩阵

| 页面     | 主要数据                     | 核心写操作                   | 必验收项                       |
| -------- | ---------------------------- | ---------------------------- | ------------------------------ |
| 续费操作 | 开通、客户、ID、业务、到期   | 手工续费                     | 预警、7 天动作边界、原子账务   |
| 订单录入 | 客户、业务、ID、结算平台     | 创建订单、快捷新增客户       | 自动回填、匹配、锁定、幂等     |
| 加卡     | ID、余额、成本、供应商       | 手工入账、反向处理           | 卡号加密、平均成本、不可变流水 |
| ID 录入  | ID 资料、余额成本、状态      | 新增、修改、启停、软删除     | 脱敏、权限、汇率成本联动       |
| 订单管理 | 订单、成本、利润、周期       | 修改、退款、取消、软删除     | 服务端利润、冲销流水、审计     |
| 客户记录 | 客户、来源、标签、状态       | 新增、修改、启停、软删除     | 手机号脱敏、快捷新增复用接口   |
| 加卡记录 | 礼品卡与余额流水             | 修改备注、反向处理           | 完整卡号不出列表、流水不可变   |
| 开通记录 | 订单、客户、ID、业务、周期   | 只读查询                     | 到期状态、脱敏、分页排序       |
| 汇率记录 | Binance、OKX、合并值、人工值 | 人工录入、立即采集、修改设置 | 失败不伪造、来源分离、精度     |
| 选项设置 | 国家、业务、供应商、结算平台 | 新增、修改、排序、启停       | 层级约束、引用保护、即时刷新   |

全局验收：

- 表单标签在左侧，必填星号在标题右侧。
- 390px、768px、1024px、1440px 无横向溢出和 UI 重叠。
- 首次加载、缓存刷新、错误保留、空状态和权限不足均有真实反馈。
- 敏感字段只在授权响应中出现，普通响应和审计不含完整值。
- 全量构建只包含当前页面 Chunk。
