# 自动注册与统一账号台账

本任务用户已于 2026-10-16 明确授权按审计方案实施，并同意新增两个可空字段。代码与离线检查完成后的证据登记于 `.runtime/auto-registration-review-20261016/IMPLEMENTATION.md`；数据库迁移、远端隔离验收、正式发布和真实注册分别验收，不能以单元测试代替。

## 资料归属

- **ChatGPT 账号**是主业务台账，保存加密邮箱、密码、注册 IP、注册国家、真实注册时间和既有业务资料。全部账号是默认视图；充值资料选择仍沿用原筛选。
- **注册结果与凭据**保存注册引擎账号、密码和 OAuth／会话凭据，以及主台账同步结果。数据位于注册模块持久卷内加密的 SQLite 记录；不把完整 Token 再复制到主台账。
- **苹果隐藏邮箱**记录邮箱池状态、标记来源、原注册任务、执行检查点及同步状态。人工标记已注册只是人工确认，不冒充官网验证成功。

## 自动保存与恢复

官网创建确认后，即使后续授权未完成，也先保存原任务的最小账号、密码和可靠注册事实，显示待授权／待补资料。恢复沿用原任务、邮箱、执行配置与密码，只继续登录授权。创建结果不明或来源冲突时继续待核对，不能盲目再次创建。

主台账同步使用稳定账号编号和同事务来源审计。新版同步指纹包含注册事实及身份状态，旧任务的指纹保持兼容。同一创建任务的后续恢复只补空字段，不覆盖人工后改的密码、国家或优惠；回收站不自动恢复。临时保存失败在有效管理员会话下有界补偿，也保留手动补存入口；重放保存资料不会重新注册或外部上传。

已启用的其他邮箱服务复用自有工作区适配层的保存、身份核验、来源绑定和同步流程，保留原服务收码差异；冻结上游源码不修改。

## 人工历史补齐

已注册且来源为人工的邮箱可先预览再补建，保留真实邮箱编号、原记录版本与人工来源。补建的密码、国家、真实注册时间未知时留空，页面显示“已注册·待补资料”。已有活动账号保持原资料；占用、版本变化、冲突和回收站分别跳过或提示。重复补建和回执丢失可以安全重试，不伪造上游账号、任务或 Token。

## 主台账展示

“注册 IP / 国家”代替独立国家与首次／最近登录展示；注册时间和注册天数使用 `registeredAt`，未知显示未记录，不用入库时间推算。原登录安全记录和充值国家核对保留。银行卡仍来自经核实的比特订单；仅移除该页银行卡删除状态及删除卡操作，不删除卡资料或订单。

注册流程不设置双重验证，仍正常核验邮箱验证码。优惠未取得与账号匹配的官网明确证据时保持待核实，人工记录优先；不按国家、新号身份或活动参数推断优惠，不为识别优惠创建结账或订阅。

## 自动注册订阅入口退役

工作区移除订阅／支付管理页面、生成支付链接、打开支付页、人工标记订阅及批量检测订阅入口，同时阻断对应代理及 Worker 路由。凭据刷新、导出和独立 Team Manager 上传保留，历史数据保留。自动充值与线上代充原有付款、订单、套餐和订阅功能不增减。
