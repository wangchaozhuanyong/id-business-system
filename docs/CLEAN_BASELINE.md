# 当前系统纯净基线

本仓库从当前 ID 业务管理系统重新建立 Git 和数据库迁移基线。

## 边界

- Git 历史从当前系统首次提交开始。
- Prisma migration 从 `20260729000000_current_system_baseline` 开始。
- 运行入口只有 `apps/admin/src/main.ts` 和 `apps/api/src/main.ts`。
- 业务源码只进入 `apps/admin/src/v2` 与 `apps/api/src/id-business-v2`。
- 本地环境文件、部署凭据、数据库备份、构建产物和视觉 QA 截图不得提交。

## 现有生产数据库

当前生产数据库保留业务数据，不因仓库重建而删除表或记录。首次使用本仓库发布前：

1. 生成生产数据库结构备份。
2. 对比生产结构与 `schema.prisma`。
3. 确认当前系统所需约束、索引和触发器存在。
4. 将纯净基线标记为已应用，不重复创建已有表。

生产数据库中的无关历史表只能在独立的数据清理任务中处理，必须另行备份和授权。
