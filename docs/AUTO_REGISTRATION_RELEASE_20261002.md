# 自动注册 GPT 统一发布

用户授权将本窗口已完成的自动注册 GPT、注册名字数据表和 ChatGPT 账号优惠状况合入 main、统一部署并验证上线。

## 发布范围

基于 `ebf1e47db15ca65a74cff73eef44fce0afdeb047` 建立项目内独立候选，保留已合并的自动充值重试、充值姓名库、开通银行卡资料和服务器执行修复。主目录的员工超级管理员、审计改版及普通字段恢复等其他窗口未提交改动未带入本次候选。

- 管理端：管理员专用导航、注册任务和名字维护，当前任务跨分页读取、邮箱验证重试、表单草稿和窄屏布局；账号优惠筛选与人工修改。复用共享界面实现，账号删除交互拆出既有逻辑以满足页面行数门禁。
- API：新增 `/api/id-business-v2/auto-registration` 下的选项、连接器、名字列表与维护、任务建立与读取、启动、当前验证邮件、取消和安全资料同步接口；本机回执为 `/local/:id`，受任务令牌、尝试次数和租约校验。
- 本机连接器：复用 Playwright 和比特浏览器，支持邮箱注册、密码与验证器核验及保守优惠识别；未知页面或人工验证暂停，不自动领取优惠或付款。连接器更新后须重启原进程。
- 数据：仅新增 `20261002160000_auto_registration` migration，创建注册名字和注册任务两张表，账号增加优惠状态、来源和观察时间；旧账号默认待核实。既有 migration 保持不变，敏感任务资料加密，关联资料禁止误删。

## 候选验证

整合后的管理端 668 项、后端 1,333 项单元测试通过；后端 25 项依赖外部测试环境的用例保持跳过。另运行本机执行器 32 项测试（含本地合成浏览器流程）及隔离 MySQL 8.4 的 3 项注册集成测试，迁移演练保留旧账号密码和备注。真实本地 API 验证名字、版本冲突、权限和优惠修改；真实渲染页面完成 12 组深浅主题与六屏宽验收，覆盖分页、空状态、失败重试、草稿和当前任务独立查询。

前后端类型与构建、定向 lint／格式、七项 UI 门禁及并发、Prisma runtime 边界、schema 校验和差异空白检查必须通过。候选证据位于项目内发布工作树 `.runtime/auto-registration-20261002/`；合并、CI、镜像、备份、迁移与线上只读验收回执统一保存于主项目 `.runtime/auto-registration-release-20261002/`。

## 生产门禁与验收

按 `PRODUCTION_RELEASE_OIDC.md` 使用通过 Quality Gate 的精确 main SHA。近期只读诊断显示生产可用空间不足 2 GiB；`RECHARGE_EXECUTION_CACHE_RECOVERY_20261002.md` 的固定五项缓存清单须用户单独批准后才能执行清理，不降低容量门槛。发布前执行新鲜备份及 S3 核验，只读财务检查、无执行中充值检查、迁移与镜像来源校验。

上线核验实际运行 SHA、容器健康、备份和新增迁移，并用现有管理员会话只读检查新导航、名字页、注册选项和账号优惠列。生产不创建合成账号或注册任务。真实 ChatGPT 注册、密码与 MFA 配置、真实邮箱收信、代理出口和官方优惠资格须用已授权资料另行业务验收；本次发布不将其宣称为已成功。
