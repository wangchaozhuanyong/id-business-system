# 自动注册 GPT 与名字数据表

本功能在管理员自己的电脑通过现有比特浏览器连接器执行，一次只处理一个已授权邮箱。代码与本地验证不代表已经上线或真实注册成功。

## 页面与资料

左侧“自动注册”提供“自动注册 GPT”和“名字数据表”。名字支持新增、修改、启停和每次最多 500 项的逐行导入；重复项跳过。自动选择启用名字中被选次数较少的项，任务建立后固定姓名和原浏览器窗口，重试不重新随机资料。

注册邮箱从“邮件验证码查询”的有效邮箱别名选择，代理使用现有已启用目录。填写真实出生日期并确认邮箱授权；当前功能接受实际年龄 20 至 45 岁的资料，不生成虚假生日。名字为空库、邮箱过期、代理不可用、连接器未更新或已有执行任务时不能开始。

“自动注册 GPT”默认显示全部隐藏邮箱，包括停用邮箱，按邮箱更新时间排序并支持邮箱、主邮箱、备注搜索和分页；原自动注册过程保留在“注册任务”页签。隐藏邮箱对应的 ChatGPT 账号已经存在时显示“已注册”，其余显示“未注册”。这表示账号资料登记状态，不代替原任务中的官网登录、密码或 MFA 核验。

管理员可在隐藏邮箱行点击“标记已注册”并确认实际注册结果，系统从源邮箱读取真实地址，使用本地事务加密保存对应 ChatGPT 账号并写脱敏审计；密码与 2FA 不被伪造，可在账号页补充。重复标记复用已有账号，不覆盖密码、2FA、停用状态或备注。未结束且授权仍有效的同邮箱注册任务阻止人工创建账号，需先结束或取消原任务；人工标记不改写自动任务的安全验证结果。该操作不新增、修改或删除邮件验证码查询中的邮箱，也不启动官网注册或付款。

ChatGPT 账号新增“优惠状况”，支持筛选和修改：待核实、0元购、半价号、全折扣号、其他优惠。旧账号默认待核实。自动识别只根据当前已核实账号明确展示的优惠卡片；没有优惠入口、普通升级按钮或普通价格不能证明资格。未识别时保持待核实，可人工修改；人工标记不会被自动结果覆盖。当前“全折扣号”和“其他优惠”通过人工核对设置。

## 本机运行

复用既有运行命令，无新增依赖或环境变量：

```sh
npm run auto-recharge:connector -- --allowed-origin=https://管理端域名
```

更新后需要重启原连接器。注册页的“本机设置”复用代理 IP 与窗口设置，选择真实存在的分组、标签，填写现有连接器和比特接口凭据。连接器仅监听本机，校验网站来源和连接器密钥，注册回执另有任务级授权、尝试次数及 45 分钟期限。

## 执行、暂停与恢复

依次处理邮箱、验证码、真实资料、官网身份核实、设置密码、验证密码登录、设置验证器 MFA、验证 MFA 登录和优惠检查。只有官网身份、密码登录及验证器登录均通过，才显示“注册与安全配置完成”。优惠可以仍待核实。

邮件读取限定目标邮箱、新邮件时间、官方发件域名和未确认接收的邮件。短码与官方验证链接只在内存流转；当前任务独立读取，列表翻页或筛选后仍可显示进度和读取邮件。页面离开即停止邮件轮询，临时验证码不进入会话草稿；连接器确认接收后才记录邮件编号，传输失败可以重试。MFA 验证器码由当前密钥计算，不把邮件验证码当作验证器码。

生成的密码和待确认的 MFA 密钥提前加密保存；失败保留任务检查点，继续使用原窗口。官网注册核实后即可在 ChatGPT 账号列表看到该账号，尚未核实的安全配置不会伪装成完成。本人验证、电话验证、无法识别的表单和存在密码的既有账号会暂停或停止，不处理验证挑战。必要时在原窗口完成资料设置，在 ChatGPT 账号编辑中补录实际密码或 MFA 密钥，再继续原任务；仍会重新核实实际登录结果。

连接器崩溃或回执未能保存时需要先恢复连接；未失效的原授权不能直接发起第二次执行。授权到期后可继续原任务。取消不撤销已经在官网完成的注册，已保存的账号及安全配置保留。

不自动点击领取、确认订阅或付款。本流程阻断支付写请求，不领取促销或修改套餐。官网界面发生变化时保留待继续状态，不能用本地模拟验证替代真实页面验收。

## 数据与接口

迁移 `20261002160000_auto_registration` 为新增迁移，不修改旧基线：

- 新增 `id_business_v2_registration_names` 和 `id_business_v2_registration_jobs`。
- ChatGPT 账号新增 `offer_status`、`offer_source`、`offer_observed_at`。
- 任务与员工、名字、代理、账号建立限制删除的关联。有关联记录的代理与账号不能直接删除；有未结束注册任务的员工不能删除，已结束记录可随既有员工接管流程转移管理权。
- 邮箱、出生日期、密码及 MFA 密钥加密保存。日志仅记脱敏邮箱、状态及配置是否核实；不记录密码、验证码、验证链接、会话或任务授权。

管理员接口前缀 `/api/id-business-v2/auto-registration`：`GET connection/options/names/jobs/jobs/:id`，`POST names/names/import/jobs/jobs/:id/launch/jobs/:id/code/jobs/:id/cancel/jobs/:id/resume-credentials`，`PATCH names/:id`。本机回执为 `POST local/:id`，使用独立任务授权。账号原有查询增加 `offerStatus`，修改增加受控优惠值与原版本校验。

2026-10-02 隐藏邮箱列表和人工标记新增 `GET mailboxes`、`POST mailboxes/:id/registered`，均复用管理员权限并返回禁止缓存的响应。列表不返回查询码或其他授权资料，标记接口通过路径接收源邮箱标识，请求体为 `{ expectedUpdatedAt }`，用源邮箱版本校验防止资料变化后误建账号，不接受客户端指定另一个邮箱地址。复用已有 ChatGPT 账号表，没有新增数据库表、字段或 migration。本地验证证据归属 `.runtime/registration-mailboxes-20261002/`，发布仍由项目统一发布窗口负责。

部署时需要在获准的发布流程中应用该迁移并更新管理端、API 和本机连接器；本次没有执行生产迁移、发布或真实注册。开放源码只参考注册步骤，未复制无明确许可证的 reg-factory 源码，浏览器操作使用项目已有 Playwright。
