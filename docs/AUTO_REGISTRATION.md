# 自动注册 GPT 与名字数据表

本功能由系统私网执行器使用内置 Camoufox 指纹浏览器执行，一次只处理一个已授权邮箱。自动注册不连接比特浏览器，不要求管理员配置本机连接器、浏览器分组或标签。代码与本地验证不代表已经上线或真实注册成功。

## 页面与资料

左侧“自动注册”提供“自动注册 GPT”和“名字数据表”。名字支持新增、修改、启停和每次最多 2000 项的逐行导入，每个名字最多 120 个字符；重复项跳过。自动选择启用名字中被选次数较少的项，任务建立后固定姓名和原浏览器窗口，重试不重新随机资料。

名字导入接口单独允许最多 1MB 的 JSON 请求，覆盖 2000 个较长中文名字；其余接口沿用默认请求大小限制。

注册邮箱从“邮件验证码查询”的有效邮箱别名选择，代理使用现有已启用目录。填写真实出生日期并确认邮箱授权；当前功能接受实际年龄 20 至 45 岁的资料，不生成虚假生日。名字为空库、邮箱过期、代理不可用、指纹执行器未就绪或已有执行任务时不能开始。

“自动注册 GPT”默认显示全部隐藏邮箱，包括停用邮箱，按邮箱更新时间排序并支持邮箱、主邮箱、备注搜索和分页；原自动注册过程保留在“注册任务”页签。隐藏邮箱对应的 ChatGPT 账号已经存在时显示“已注册”，其余显示“未注册”。这表示账号资料登记状态，不代替原任务中的官网登录、密码或 MFA 核验。

管理员可在隐藏邮箱行点击“标记已注册”并确认实际注册结果，系统从源邮箱读取真实地址，使用本地事务加密保存对应 ChatGPT 账号并写脱敏审计；密码与 2FA 不被伪造，可在账号页补充。重复标记复用已有账号，不覆盖密码、2FA、停用状态或备注。未结束且授权仍有效的同邮箱注册任务阻止人工创建账号，需先结束或取消原任务；人工标记不改写自动任务的安全验证结果。该操作不新增、修改或删除邮件验证码查询中的邮箱，也不启动官网注册或付款。

ChatGPT 账号新增“优惠状况”，支持筛选和修改：待核实、0元购、半价号、全折扣号、其他优惠。旧账号默认待核实。自动识别只根据当前已核实账号明确展示的优惠卡片；没有优惠入口、普通升级按钮或普通价格不能证明资格。未识别时保持待核实，可人工修改；人工标记不会被自动结果覆盖。当前“全折扣号”和“其他优惠”通过人工核对设置。

ChatGPT 账号清单提供独立“国家”列，新增与编辑可选择或清空国家。自动注册在官网身份核实完成时，通过原注册浏览器的同源网络观测读取真实出口国家，保存首次确认的注册国家快照；不依据代理目录配置、服务器或首次／最近登录的国家猜测。网络观测失败或旧连接器未提供国家时显示“未记录”，普通导入和隐藏邮箱人工标记也保持未知，可在编辑中补充。手动修改或清空后，重复注册回执、恢复任务与后续密码、MFA、优惠回执均不覆盖该值。国家使用两位地区代码保存，界面展示简体中文名称；仅传国家，不把注册出口 IP 加入回执、数据库或日志。

## 代理与使用说明

注册表单直接从“代理 IP 管理”选择启用代理，复用动态提取和固定代理的协议、链接与加密账号密码。无需再配置“代理 IP 与窗口设置”；该抽屉原有使用说明仍用于其他既有入口。目录停用、删除或失效时，服务端停止启动，不回退历史连接资料。

注册与充值共用已有默认代理引用。空白注册表单自动带入默认代理，已有手动选择保留；本次注册使用任务表单中的选择。新任务每次只读准备先提取一次代理，再启动新的指纹浏览器，核实出口国家并打开官网初始页面；Context、出口和初始页面共用 20 秒。注册资料提交之前，动态代理连接失败或超过这段时间时，确认关闭失败窗口后重新提取 IP、生成新指纹，最多尝试 10 次（含首次）。静态代理失败直接停止；本人验证、无效配置、授权失败或清理未确认不自动轮换。准备成功后复用页面，提交注册资料后与暂停继续均保留原代理和原窗口。

注册页和开始注册抽屉的标题右侧“使用说明”介绍邮箱授权、代理、名字、执行和账号入库、验证码、原任务恢复及本人验证。任务接收结果不明时保留输入和任务编号，先查看原任务，不创建第二个注册窗口。

默认代理复用已有 JSON 配置的 `proxyId`，本轮没有新增数据库表、字段、环境变量或迁移。前一轮代理设置证据见 `.runtime/registration-proxy-settings-20261002/RESULT.md`；本轮指纹切换证据见 `.runtime/registration-builtin-browser-20261002/RESULT.md`。

## 系统执行器

注册和服务器充值复用既有 `auto-recharge` 私网 Worker、地址和认证配置。新增经用户允许的 Camoufox 0.5.6 依赖和 152.0.4-beta.30 内核，构建时校验固定下载文件的 SHA-256，运行时无需下载内核、扩展或 GeoIP 数据。没有普通 Chromium 回退。安装与发布边界见 `BUILTIN_FINGERPRINT_BROWSER.md`。

密码、待确认 MFA 密钥和任务授权只从 API 传给私网 Worker；管理端接收任务编号、尝试次数和接收状态，不接收这些秘密。回执限制任务授权、当前尝试和 45 分钟期限；管理员身份、邮箱授权失效后不能继续读码。

## 执行、暂停与恢复

依次处理邮箱、验证码、真实资料、官网身份核实、设置密码、验证密码登录、设置验证器 MFA、验证 MFA 登录和优惠检查。只有官网身份、密码登录及验证器登录均通过，才显示“注册与安全配置完成”。优惠可以仍待核实。

邮件读取限定目标邮箱、新邮件时间、官方发件域名和未确认接收的邮件。Worker 在等待邮件步骤通过任务授权向 API 读码，不依赖管理端保持页面打开；Worker 确认接收后才记录邮件编号，传输失败可以重试。临时验证码不进入会话草稿；管理员手动提交时绑定当前尝试和步骤。MFA 验证器码由当前密钥计算，不把邮件验证码当作验证器码。

生成的密码和待确认的 MFA 密钥提前加密保存；失败保留任务检查点，继续使用原窗口。官网注册核实后即可在 ChatGPT 账号列表看到该账号，尚未核实的安全配置不会伪装成完成。密码/MFA 核验在同一浏览器、相同代理和指纹的新 Context 中进行，避免把已登录 Cookie 当作验证通过。本人验证、电话验证、无法识别的表单和存在密码的既有账号会暂停或停止，不处理验证挑战。必要时由管理员在执行器原窗口处理；当前版本没有新增远程桌面入口。账号页可补录实际密码或 MFA 密钥，再继续原任务重新核实。

执行器崩溃或原窗口关闭后停止为“原窗口丢失”，先核对官网账号，不另开窗口重复注册；原 Cookie 和凭据不落盘。已有比特任务不自动转换为新指纹窗口。回执未能保存时先恢复系统连接；未失效的原授权不能直接发起第二次执行。取消先撤销任务授权，再通知执行器关闭窗口，关闭未确认时页面明确提示管理员检查。取消不撤销官网已完成的注册，已保存的账号及安全配置保留。

不自动点击领取、确认订阅或付款。本流程阻断支付写请求，不领取促销或修改套餐。官网界面发生变化时保留待继续状态，不能用本地模拟验证替代真实页面验收。

## 数据与接口

此前自动注册使用向前迁移 `20261002160000_auto_registration`，不修改旧基线；本轮浏览器切换不新增迁移：

- 新增 `id_business_v2_registration_names` 和 `id_business_v2_registration_jobs`。
- ChatGPT 账号新增 `offer_status`、`offer_source`、`offer_observed_at`。
- 任务与员工、名字、代理、账号建立限制删除的关联。有关联记录的代理与账号不能直接删除；有未结束注册任务的员工不能删除，已结束记录可随既有员工接管流程转移管理权。
- 邮箱、出生日期、密码及 MFA 密钥加密保存。日志仅记脱敏邮箱、状态及配置是否核实；不记录密码、验证码、验证链接、会话或任务授权。

管理员接口前缀 `/api/id-business-v2/auto-registration`：`GET execution/options/names/jobs/jobs/:id`，`POST names/names/import/jobs/jobs/:id/launch/jobs/:id/code/jobs/:id/cancel/jobs/:id/resume`，`PATCH names/:id`。移除管理端 `connection` 和 `resume-credentials` 秘密分发接口；`code` 改为绑定尝试和步骤的手动提交。Worker 回执沿用 `POST local/:id`，新增授权读码 `POST local/:id/code`。私网 Worker 提供注册健康、派发、同尝试状态查询、继续、验证码与取消端点，均复用现有 Worker 认证，不公开给管理端。账号原有查询增加 `offerStatus`，修改增加受控优惠值与原版本校验。

2026-10-02 隐藏邮箱列表和人工标记新增 `GET mailboxes`、`POST mailboxes/:id/registered`，均复用管理员权限并返回禁止缓存的响应。列表不返回查询码或其他授权资料，标记接口通过路径接收源邮箱标识，请求体为 `{ expectedUpdatedAt }`，用源邮箱版本校验防止资料变化后误建账号，不接受客户端指定另一个邮箱地址。复用已有 ChatGPT 账号表，没有新增数据库表、字段或 migration。本地验证证据归属 `.runtime/registration-mailboxes-20261002/`，发布仍由项目统一发布窗口负责。

2026-10-03 注册国家新增迁移 `20261003013000_chatgpt_registration_country`，在 `id_business_v2_chatgpt_accounts`、`id_business_v2_registration_jobs` 各新增可空 `registration_country_code CHAR(2)`；用户已批准此增量结构变更。保留旧账号与任务，历史国家不回填。复用账号列表／新增／修改接口：列表返回 `registrationCountryCode`，新增可省略，修改可传两位代码或 `null` 清空；未传不改原值，编辑沿用 `expectedUpdatedAt` 校验及原管理员权限和审计。仅 `registered` 类型的任务回执可带可空 `registrationCountryCode`，其他类型不能改写注册国家。该国家功能已在本次候选的 main 基线发布；本轮保留迁移、国家快照和兼容旧连接器缺少国家回执的处理，不再次创建迁移。本地证据归属 `.runtime/chatgpt-country-20261003/`，本轮未执行真实注册。

部署时需要在获准的统一发布流程中更新管理端、API 和 Worker，并确认此前注册迁移已存在；本窗口未提交、推送、发布、生产迁移或真实注册。开放源码 [reg-factory](https://github.com/tiantianGPU/reg-factory/blob/main/register_chatgpt.py) 仅参考注册步骤，未复制无明确许可证的实现；原项目使用比特，不等于本系统当前实现。内置内核直接采用 [Camoufox](https://github.com/daijro/camoufox) 开源项目，经固定版本安装由现有 Playwright 驱动。
