# 在线工具布局

以老版已提交的工作区和工具抽屉为参照。五项入口按老版顺序单列显示，右侧箭头进入各自抽屉，关闭详情回到工具列表。使用新版主题令牌。页面顶栏直接提供个人工具、在线工具、话术文案三个按钮，分别打开对应右侧抽屉；抽屉显示当前标题和关闭按钮，正文独立滚动。工具的输入草稿和已选页签继续按会话保留。

个人工具沿用老版单列快捷网址和底部管理入口，管理页使用行列表及就地新增和修改。话术文案采用单行卡片，提供搜索、排序、复制、查看全文和更多操作。自定义排序支持拖动、方向键和上移／下移；按最近修改排序使用服务端记录的文案修改时间。

| 工具 | 结构与操作 |
| --- | --- |
| 计算 2FA 验证码 | 单个／批量输入在上，临时结果和已保存账号在下。已保存账号可按名称或签发方搜索，分页后仅自动刷新当前页，并显示有效倒计时 |
| 网站监控 | 通过顶部固定的“访问统计”“访问记录与 IP”“网站检测”页签切换，始终只显示一组内容。访问记录含每日统计、独立 IP 数和分页明细。完整 IP 查阅记审计，30 秒后恢复遮挡 |
| 抖音解析 | 作品输入、粘贴、开始解析与结果卡片。结果按视频、原声、图片分组，显示格式、规格和下载凭证有效期 |
| 邮箱查询与管理 | 查询与管理使用同一个 860px 上限的右侧抽屉，切页不改变宽度，手机全屏。买家查询页入口与固定页签同排，窄屏自然换行。邮箱池按一个账号一行显示，默认每页 20 条，可选 50／100 条并输入页码跳转；状态、到期、最近查询各占一列；长查询码单行省略，与“复制”同排，复制时保留完整值；邮箱资料最多两行。查询支持返回封数、刷新、邮件详情、安全链接、正文和验证码复制。邮箱池含备注、类型和状态筛选、分页、授权验证、原查询码显示与复制、有效期设置和到期时间同步。Microsoft 批量导入逐个授权 |
| Google 表格同步 | 依已确认范围保留待开发入口 |

- 前端入口、功能、样式分别位于 `frontend/prototype.js`、`frontend/operations-prototype.js`、`frontend/prototype.css`。继续使用现有统一会话。
- 邮箱池既有 `/api/local/tools/mailbox-pool` 增加同源管理员 POST 读取查询码，并记录审计。登记、换授权与批量登记先验证，再核对版本并保存；查询码有效期同步保持原码。复用既有加密文档，无数据库结构迁移。
- 真实站点的 GA4、采集和 Microsoft 授权需要用对应环境的配置验收。媒体回环执行器通过健康检查，实际公开作品解析成功，原声下载返回 503。
