## 实现结果

- 自动充值主入口改为“比特浏览器充值”，本机执行登录、套餐核实、报价和付款；服务器保留权限、资料、任务、账务、历史与审计职责。
- 登录只保留“授权 JSON”与“账号密码”。账号密码直接选择 ChatGPT 账号资料库中已保存密码的账号；移除重复的“已保存账号”第三个选项。没有密码时引导补充已有账号资料。
- 首次开通和同账号 Go→Plus、Plus→官网可用 Pro 使用独立任务、重新核价和新的一次性确认。官网已是目标套餐时不重复付款；没有升级入口或无法确认报价时停止。
- 付款前真正等待人工确认。一次性授权只存在本机助手和当前页面内存中，绑定账号、套餐、报价、窗口及有效期；确认后重新检查，报价变化、过期、错误账号或重复确认均不能发起付款。
- 付款成功与套餐开通分别验证。结果不明只复查原订单；同账号任何尚未闭合的付款阻挡新付款。已核实成功但仍待补财务日期的订单不会阻挡重新读取官网套餐。
- 仅复用同操作人、同真实账号且有完整官网付款及开通证明的充值窗口。窗口失效或账号错配时停止，不接管注册或手工窗口，也不通过名称猜测窗口归属。
- 账单地址使用实际所选资料，包括第二行；可复用已使用且仍可用的地址。保留原付款历史和同一账号关联，不改余额或旧订单。
- 成功后的清卡不再立即显示必填红字。结果页分别展示“升级前套餐”与官网核实的“当前套餐”，缺少证明时显示尚未核实。
- 充值助手与注册助手使用独立进程、任务队列、角色、端口和运行目录。新充值请求不再进入服务器浏览器执行流程；旧服务器任务仍可读取并按原安全规则停止。

## 本机启动方式

发布并取用对应版本后，在该项目目录启动充值助手：

```sh
npm run auto-recharge:connector -- --allowed-origin=https://你的管理端域名
```

需要本机 Python 3.11 或更高版本、已安装并登录的比特浏览器，以及比特本地 API 设置。独立安装包未制作。

充值默认端口 `55322`，运行目录 `.runtime/bitbrowser-recharge-assistant/`；注册默认端口 `55321`，运行目录 `.runtime/auto-recharge-connector/`。既有注册进程未停止或替换。需要另启动注册助手时使用：

```sh
npm run auto-registration:connector -- --allowed-origin=https://你的管理端域名
```

既有注册设置地址 `55321` 会为充值派生 `55322`；自定义端口保留。已有助手必须升级到充值角色与版本 4，旧助手不会在开始前被静默兼容。
