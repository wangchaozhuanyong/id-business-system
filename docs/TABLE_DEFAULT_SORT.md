# 业务列表默认排序

先筛选，再排序和分页。列表使用对应的业务时点。带时区的日期按同一时间轴比较，本地业务日期按北京时间解释。缺少主要日期时依次使用表中列出的后备字段，日期仍未知的记录排在末尾。时间相同按记录编号稳定排序。

| 页面或列表 | 默认顺序 |
| --- | --- |
| 全部订阅、客户订阅、自有订阅及各产品订阅 | 账号的最新订阅开始时间倒序，缺失时用来源订单创建时间 |
| 即将到期 | 每个账号最早符合提醒范围的有效订阅到期时间升序 |
| 已到期 | 最近到期的周期在前 |
| 无邮箱、死号订阅 | 无邮箱按原单创建时间倒序。死号按状态登记时间倒序，缺失时按订阅开始时间 |
| 按银行卡、按苹果 ID 查看订阅 | 有效订阅按到期时间升序优先展示，其他有日期的记录按到期时间倒序，无日期排末尾。银行卡汇总及其关联订阅沿用该顺序 |
| 续费管理、租户待处理续费 | 按到期时间升序。待处理队列中的已逾期记录按逾期最久优先 |
| 已处理续费、租户已处理提醒 | 按新续费单或处理记录的时间倒序 |
| GPT、Claude、Gemini、Grok 订单与订单统计明细 | 按订单创建时间倒序，历史单缺失时用订阅开始时间 |
| 已撤单、退款单及回款明细 | 撤单按撤单记录时间，退款单按最近一笔退款时间。退款、银行卡回款及 Apple 回款明细按实际发生时间倒序，待回款按登记时间 |
| 订单补全、手工与历史单 | 自动订单按实际开通时间倒序，依次回退到订阅开始、创建时间。手工与历史单按创建时间倒序，缺失时用订阅开始时间 |
| 客户资料、租户资料、员工账户、录入工作台记录 | 按原始录入时间倒序 |
| 谷歌、微软邮箱，GPT、Claude、Gemini、Grok 账号及苹果 ID 余额主档 | 全部和库存按录入时间倒序，历史资料可回退到导入或注册时间。已提取看提取时间，已使用看使用时间，死号和解封中看状态变更时间 |
| 苹果主邮箱、隐藏邮箱、收件、导入和操作记录 | 按登记、收件、导入或操作各自的时间倒序 |
| 提取批次、归还、导入、首次登记和付租批次 | 按各自的提取、归还、导入、首次登记或建批时间倒序 |
| 邮箱池、保存的验证器账号 | 按已有登记顺序最新在前。邮箱池的待授权候选单独列在已登记资料之后 |
| 冻结银行卡、订单汇率来源、实付凭据 | 分别按冻结时间、报价时间和扣款日倒序 |

订阅页签各自保留手动排序选项。切换排序时从第一页重新读取。搜索和分页使用同一个已排序的结果集。

- 充值码和申请记录按发放、申请时间倒序，地址管理按创建或使用时间倒序。审计和登录日志按最新记录优先，监控事件先按待处理优先级再按时间。
- 汇率历史按报价时间，采集与设置变更按登记顺序。当前汇率依币种配置排列，套餐、银行卡类型、话术和下拉设置使用各自的业务顺序。
- 员工待处理统计、客户流失和图表按当前指标、提醒时间或统计周期展示。续费关系明细按订阅周期，导入预检按源表行号，充值执行记录按执行器的事件顺序。
