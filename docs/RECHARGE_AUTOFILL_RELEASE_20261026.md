## 用户可见变化

- “保存设置”记住当前系统账号选中的连接；刷新后继续使用该连接。其他系统账号独立保存。
- 当前管理员可从卡池已有临时内存回填安全码，读取不续期；过期、切卡或切换身份后不会错填。
- 比特 Local API 返回 HTTP 200 但拒绝请求时，显示受控的登录或权限提示。
  此修复不替用户登录比特浏览器或扩大子账号权限。

姓名和地址 500 的独立生产原因是账单分配表缺少应用权限。经用户单独授权，
仅为现有应用账号补齐该表 SELECT、INSERT、UPDATE；生产回读通过，无 DELETE、转授权、
密码变更或业务数据写入。该权限已修复，不由本发布重复执行。
