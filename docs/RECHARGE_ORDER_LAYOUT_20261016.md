# 充值订单紧凑布局

## 范围与实现

在 `codex/online-order-sync-20261016` 的已发布订单功能之上，只调整管理端布局。未修改后端、接口、数据库、账务、订单同步或付款行为。

- 渠道页签、使用说明、手工录入和更多操作组成第一行。
- 原筛选栏组成第二行，增加到期状态下拉，沿用原 `expiry` 状态与会话草稿。
- 业务清单／回收站移入表格标题栏，右侧保留总数和列设置。
- 收费设置、新增币种、比特新增银行卡／线上卡池、线上历史补录合并到更多操作，继续使用原抽屉及权限。
- 两渠道的筛选、分页、列设置、表单和收费草稿保持隔离；无线上权限时仍能切回比特渠道。
- 共用 `V2PageContext` 和 `V2SectionHeading` 增加可选导航插槽，不传时保留原行为；页面不复制控件皮肤。
- 浏览器验收发现菜单关闭会隐藏后代抽屉，已把抽屉本体移出菜单，菜单仅保留原操作触发器。
