# 网站管理统一方案

使用现有的监控中心、数据中心和系统设置。管理台用业务名称显示状态、操作及下一步，排错信息使用可复制的诊断编号。现有充值执行和付款流程沿用原入口。

| 入口 | 数据范围和更新 | 保存行为 |
| --- | --- | --- |
| 监控中心 → 性能与错误 | 近 24 小时或 7 天的页面等待、服务端处理、样本数、失败率及慢操作。输入诊断编号查询时间、操作和处理建议 | 测量只上报固定操作、耗时和结果 |
| 监控中心 → 网站监控 → 运行状态 | 实际服务器资源与后台来源状态，复用既有监控刷新 | 只读 |
| 数据中心 → 数据健康 | 订单、库存和同步回执；按异常种类与分页读取。保留当前筛选，异常链接到原有页面 | 只读 |
| 数据中心 → 备份与恢复 | 现有只读回执、单独的隔离恢复回执。校验时间和资料时间分别展示 | 只读。恢复在授权的隔离环境执行 |
| 数据中心 → 导出与保留 | 按日期、类别、产品和状态下载客户或订单。可以选简表或业务明细。业务明细包含必要的联系方式或金额 | 下载业务明细需安全确认，记录导出人、日期范围和条数。保留期限供查看 |
| 系统设置 → 系统信息 | 发布制品携带的版本、正式域名、北京时间、验证的最近发布时间 | 只读，操作记录沿用现有入口 |

运行状态显示站外检测、服务器资源及同步任务的最近成功、积压和问题说明。备份与恢复分别显示网站业务和自动代充的「已备份」「已校验」「已恢复验证」。未采到的资料标为待确认。性能趋势只在有至少 20 笔成功样本时展示约 95% 成功操作能在多长时间内完成。

## 人员分工

每人一个账号、一个主角色。修改角色、所属主管、密码或启用状态后，原有登录失效。现有账号沿用原角色，超级管理员可在「员工与权限」逐人调整角色和分组。

| 角色 | 日常工作 | 管理范围 |
| --- | --- | --- |
| 超级管理员 | 日常管理、员工角色、登录安全、监控通知、全局设置和紧急恢复 | 超级管理员账号由系统保护 |
| 管理员 | 管理客户、订单、订阅、邮箱和账号库存，处理代充业务，查看运行状态、数据健康、备份和操作记录。可查看完整的日常业务资料 | 邮箱分类、代付国家及相关下拉项、汇率采集设置、人员权限和登录策略由超级管理员负责 |
| 主管 | 查看所属小组的员工、客户和订单数量，新增业务 IP | 主管可登记个人比特执行 IP 或新增自动代充业务代理。银行卡、账单、付款资料和登录网络策略仅向对应角色开放 |
| 财务 | 导入、停用自动代充卡，配置允许套餐和取卡规则，查看自动代充账单。通过「财务续费」登记续费实付和用卡 | 网站总览、订单、订单统计和费用凭据只读。卡池列表显示尾号、状态和允许套餐。业务订单的退款和更正由业务管理员处理 |
| 注册员 | 登记邮箱、平台账号、动态验证码资料及已开通的 Apple 隐藏邮箱。查询本人登记邮箱的邮件验证码 | 主邮箱授权由管理员负责。员工登录两步验证与业务动态验证码各自独立 |
| 员工 | 在快速操作中查本人客户、录入客户、提交续费给财务、补全订单和申请充值码 | 只查看本人经办或已分配的客户及订单。财务登记后由员工提交续费新订单 |

## 续费交接

1. 员工从「快速操作 → 续费管理 → 选订单」选中一笔或多笔，核对记录并按「确认送财务」。管理员可以处理全部订单，主管可以提交本组订单。电脑在页面右侧切换办理进度，手机在列表上方切换。已送出的订单可在「已送财务」查看。
2. 财务在「快速操作 → 财务续费」从表格接手一笔。接手后该财务人员负责登记实际付款金额、原币和用卡。换卡只登记到本次续费，旧订单的付款和用卡原样保留。财务核对实际付款并通过安全确认后交回。尚未付款的申请可填写原因退回，由业务人员核对后重新送出。
3. 财务已提交的订单出现在「续费管理 → 待补资料」。员工补客户实收、实际开通时间和新到期时间，已有账号和财务登记的付款资料自动带入。提交成功后生成独立新订单，并在「办理记录」显示新订单编号。

同一笔原订单只允许一个有效申请。财务接手、登记、退回和最终入单均记录人员与时间。财务工作台登记已经发生的实付。主管查看本组进度时没有用卡资料。原版线上自动代充继续使用已有路径。订单列表取消勾选和付租批次创建入口，历史批次可从原有详情及待处理入口查阅。管理员从「续费提醒」继续设置提醒时间、话术、拒续和恢复提醒。

## 登录安全与再次验证

- 正式域名接通真人验证后，登录先完成真人验证，再检查密码及已绑定的两步验证。系统限制同一账号、可信网络来源和全站的尝试次数，超过限额暂等一分钟。验证码和恢复码按单次使用处理。 [Cloudflare 登录令牌验证规则](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/)
- 「我的账号」可绑定验证器、查看剩余恢复码、批准或移除设备、退出已登录的设备。登录限制识别已批准的浏览器。登录网络名单由超级管理员维护。
- **敏感操作**包括新增或停用员工、调整角色或重设密码，绑定变更或批准设备，修改登录网络，导入或停用自动代充银行卡、变更允许套餐或严格取卡规则，登记续费实付和换卡，新增会参与自动代充的业务代理，查看完整的订单用卡资料，以及下载含联系方式或金额的业务明细。关键监控通知和汇率采集设置也需要安全确认。注册员为工作账号获取验证码时只读取对应的登记记录。
- 安全确认使用身份验证器中的六位验证码，确认有效五分钟。切换报表、筛选订单、查看对账、日常客户录入等按角色正常使用。安全操作和导出留在操作记录里。

## 实施与验收

1. 在隔离资料上核对六角色及旧会话失效。验证真人校验、验证码重用、设备批准、公司网络以及运维恢复。暂未接入的保护项如实显示状态。上线与紧急恢复见 [登录安全运维说明](ACCESS_AND_SECURITY_PLAN.md)。
2. 核对站外探针在网站中断时能独立发告警。核实两套异地备份回执，分别在隔离环境恢复并回读代表性记录。实际收到的通知和演练回执用于确认结果。 [生产部署与恢复规则](PRODUCTION_OPERATIONS.md)
3. 核对只读角色访问、筛选后导出的范围和操作记录。确认监控页面静置不额外刷新业务列表，诊断记录避开业务正文与凭据。性能基线随正式使用积累。 [Google SRE 监控指南](https://sre.google/sre-book/monitoring-distributed-systems/) · [OWASP 日志指南](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html)
