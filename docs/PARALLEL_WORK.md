三条工作在同一独立目录开发，按模块划分写入责任。侧栏所在的父项目只用于归类。

| 窗口                             | 本轮交付                                                  | 写入范围                                                                                                                                                                                                                    |
| -------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 规划管理系统模块化与页面设计     | 隐藏邮箱历史归属预检、库存历史保护、公共入口和本机集成    | `server/apple-relay/`、`server/inventory-history.mjs`、`frontend/apple-relay-prototype.js`、`frontend/prototype.js`、`frontend/operations-prototype.js`、`server/preview.mjs`、`server/local-business*.mjs`、登录和公共入口 |
| ID 独立新版 · 汇率快照与利润核算 | 财务与恢复、工具箱配置读取安全和联调清单                  | 财务和备份模块，以及本轮 `server/tools/` 内的配置读取模块、工具专项测试和 `ONLINE_TOOLS.md`                                                                                                                                 |
| 独立新版：修复客户资料与录单联动 | 线上 ChatGPT 代充接入统一会话，继续维护比特授权 JSON 登录 | `modules/recharge/`、`frontend/bitbrowser-local.*`、`frontend/recharge-integration.css`、充值专项测试                                                                                                                       |

需要公共入口或共享页面变更时，由模块窗口交付接口契约、最小改动说明和隔离测试结果，主窗口再串行接入。公共入口和 `4348` 由主窗口统一管理。两个模块窗口各自使用随机回环端口、内存或独立测试数据。

正式部署待全部开发验收后再安排。真实付款、生产数据库和旧版运行环境不属于本轮。
