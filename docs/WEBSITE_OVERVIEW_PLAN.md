# 网站总览

入口为「网站总览」，使用经营指标、趋势和当前待处理说明业务情况。数字从各数据区进入原业务页核对。

## 经营区间

默认近 7 天，可切换今日、近 30 天或自定义起止日期。经营统计默认按北京时间录入日和人民币显示，也可切换实际开通日及马币。自定义范围包含起止日，涉及今日时截止本次数据快照。上期整体向前平移对应天数，保留相同截止时刻。今日按小时汇总，预设跨日范围按日；自定义长区间分成最多 30 组并显示每组天数。日期、趋势指标和明细展开状态在当前页面会话内保留。

区间栏始终单行。宽屏左侧展示本期、北京时间和上期，右侧排列范围切换、刷新、更新时间和指标口径。空间收窄时通过「上期对比」查看完整时间，手机点按日期查看本期、上期、时区和最近成功更新时间；范围使用选择框，刷新和指标口径保留带文字说明的图标按钮。

四项经营卡片共用标题、数值和辅助信息的行轨道，数值字号及右侧单位一致，多币种逐行保留原币与比较值。桌面四列、平板两列，560px 及以下单列；长金额完整换行。

| 指标 | 口径 |
| --- | --- |
| 新建订单 | 按所选日期口径统计符合经营统计条件的订单。续费新单计入，已撤单另列。 |
| 订单实收 | 已录入的实际收款按所选订单日期及原币分列。客户退款按登记时间和原币另列。 |
| 自动计算利润 | 和订单统计共用订单范围、实收、费用规则、汇率、到账回款及开卡费分摊口径。开卡费未分摊时显示已知部分。列出计算缺项、参考核算和开卡费未分摊笔数。任一比较区间有计算缺项时暂缓利润环比。 |
| 新增客户 | 按客户创建时间统计，客户编号去重。 |

经营趋势可切换订单量与利润，按时段展开核对准确值。订单与撤单分开展示。分析句以本期和上期各业务的订单差额为依据，显示变化最大的业务。业务构成分 GPT、Claude Pro、Claude Max、Gemini 和 Grok，其他业务单列，订单占比以本期未撤单订单为分母。

趋势图每个日期／小时均支持鼠标悬停、键盘聚焦与手机点按查看浮层，零值也保留完整时段的命中区域。浮层显示北京时间、订单量与撤单笔数，或所选币种的自动计算利润、已计算及缺项笔数。利润未知时显示计算缺项。左右方向键及 Home／End 可逐项查看，Escape 或点按外部关闭；移动到浮层内仍可阅读。浮层不挤动原布局，切换指标、区间或页面后不保留旧提示，原每日／每小时数据入口继续保留。

业务构成与「收款与利润」共用一行，可用内容宽度达到 1100px 时各占一半，窄屏上下排列。右侧列出已录入实收、缺少实收资料、已计算利润及计算缺项笔数。两项比例以同一批经营订单为分母，并注明已撤单和参考核算笔数。两组独立显示数据时间，失败保留原值，首次缺数显示「—」，无订单不计算比例。

## 当前快照

- 当前待处理覆盖续费、订单待补资料、已领用待处理、苹果待回款、充值码申请待处理和 Claude 付租待发放。充值码仅对有审批权限的账号按待审核或待发码核对的申请笔数统计。付租按已建批次内待发放或发放失败的明细计数。正数指向原业务明细。读取中或失败的类别显示对应状态。
- 库存按类型分行，独立列出已登记、可提取、已领用、死号、解封中、邮箱停用、冻结、封控中、养号中、缺登记时间和资料异常。已登记包括当前保存的已使用资料，排除已删除的隐藏邮箱。可提取沿用资格和占用规则，Claude 应满足养号条件，苹果隐藏邮箱显示按提取规则检查的可提取数量及最近检查时间，微软邮箱的可提取和已领用为不适用。异常按上述顺序每条只计一次，与占用状态可能重叠，各列不可直接相加。0 代表确认没有，— 代表不适用或尚未取得数据；邮箱停用仅适用于隐藏邮箱。窄屏固定类型列、横向滚动查看统计。
- 库存与客户容器的可用宽度达到 1440px 时，采用左库存、右客户的并排布局，对齐标题、内容起点和底部更新时间，库存保留完整多列的宽度；不足时两区上下排列、各占整行。
- 客户状态复用客户流失和续费规则。主要指标按客户去重列有效服务、续费待跟进和已确认流失；补充待处理续费单、待生效客户、近 7 天流失和待核对订单。续费及核对以订单笔数计，客户数不能与订单数相加。待生效和近 7 天流失复用客户流失页面的现有口径。点击补充项进入原明细，待生效、近期流失和待核对会定位到对应页签或筛选并清除旧查询条件。客户状态属于当前快照，不随经营区间切换。

## 数据覆盖和权限

总览复用订单、客户、库存和苹果台账的现有读取接口与数据变更事件。按区刷新，各区保留最后一次成功数据和时间。苹果台账读取失败时，待回款保留上次成功结果；有原单实收和成本的订单继续计算利润。库存读取失败时，库存、领用待处理、客户和续费统计保留旧数据。首次尚未取得数据时显示「—」，成功且确认为空时显示 `0`。

员工按既有权限查看授权库存。经营、财务和客户汇总沿用订单统计权限。收录系统已登记订单和已同步的代充订单。网站访问、代充全量任务、监控及其余外部数据在对应模块核对，业务占位保留在各自栏目。总览的「指标口径」提供数据覆盖说明。

## 验证入口

运行新版主线的 `npm test` 及网站总览离线浏览器专项。浏览器通过请求拦截使用合成数据，验证深浅主题、桌面及手机布局、区间比较、分区失败、重试、员工权限和切页恢复。
