# 网站总览

入口为「网站总览」，使用经营指标、趋势和当前待处理说明业务情况。数字从各数据区进入原业务页核对。

## 经营区间

默认近 7 天，可切换今日和近 30 天。近 7 天及近 30 天从北京时间第一个自然日零时开始，到本次数据快照为止。上期整体向前平移对应天数，保留相同截止时刻。今日按小时汇总，其余按日。日期、趋势指标和每日数据展开状态在当前页面会话内保留。

| 指标 | 口径 |
| --- | --- |
| 新建订单 | 按订单创建时间统计未撤单订单。续费新单计入，已撤单按原创建时间另列。 |
| 订单实收 | 只统计已确认的实收金额，按创建时间和原币分列。客户退款按登记时间和原币另列。 |
| 已核算利润 | 复用订单冻结的汇率、费用、已确认回款和同卡开卡成本分摊，按创建时间归集为人民币。显示已核算和待核算笔数，明确标出其中的参考核算笔数及 GPT 开卡费未分摊笔数。任一比较区间有待核算订单时暂缓利润环比。 |
| 新增客户 | 按客户创建时间统计，客户编号去重。 |

经营趋势可切换订单量与利润，按时段展开核对准确值。订单与撤单分开展示。分析句以本期和上期各业务的订单差额为依据，显示变化最大的业务。业务构成分 GPT、Claude Pro、Claude Max、Gemini 和 Grok，其他业务单列，订单占比以本期未撤单订单为分母。

## 当前快照

- 当前待处理覆盖续费、订单待补资料、已领用待处理和苹果待回款。正数指向原业务明细。读取中或失败的类别显示对应状态。
- 库存按现有可提取资格和占用规则统计。Claude 应满足养号条件，苹果隐藏邮箱可提取资格需核验，微软邮箱显示已登记量。
- 客户状态复用客户流失和续费规则。按客户去重列有效服务、续费待跟进和已确认流失，待核对订单以笔数另列。

## 数据覆盖和权限

总览复用订单、客户、库存和苹果台账的现有读取接口与数据变更事件。按区刷新，各区保留最后一次成功数据和时间。苹果台账读取失败时，依赖该台账的利润区间及待回款保留旧数据。库存读取失败时，库存、领用待处理、客户和续费统计保留旧数据。首次尚未取得数据时显示「—」，成功且确认为空时显示 `0`。

员工按既有权限查看授权库存。经营、财务和客户汇总沿用订单统计权限。收录系统已登记订单和已同步的代充订单。网站访问、代充全量任务、监控及其余外部数据在对应模块核对，业务占位保留在各自栏目。总览的「指标口径」提供数据覆盖说明。

## 验证入口

运行新版主线的 `npm test` 及网站总览离线浏览器专项。浏览器通过请求拦截使用合成数据，验证深浅主题、桌面及手机布局、区间比较、分区失败、重试、员工权限和切页恢复。
