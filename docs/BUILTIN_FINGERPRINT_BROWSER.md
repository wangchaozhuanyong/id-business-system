# 系统内置指纹浏览器

2026-10-03 统一发布候选。自动注册和服务器充值使用私网 Worker 的原生 Camoufox 启动层；自动注册无需比特浏览器或本机连接器。自动充值保留比特浏览器本机充值、仅登录窗口和对应设置，选择服务器充值时才使用内置浏览器。尚未发布，真实注册与付款结果未验收。

## 执行方式

系统从已有代理 IP 目录读取任务选中的最新启用资料。新任务在任何账号资料写入之前进行只读准备：每次动态提取一次 IP，启动新的独立指纹浏览器，创建 Context、核实实际出口国家并打开官网初始页面。Context 创建、出口探测和初始页面导航共用 20 秒预算；提取另有 20 秒上限，内核启动与指纹采样／去重共用 30 秒上限，资源清理另有最多 5 秒的单项上限。失败窗口确认关闭后，动态代理重新提取并生成新指纹，最多尝试 10 次（包含首次），10 次都失败则停止。供应商重复返回已失败的出口时，拒绝进入账号操作并计入尝试次数；不保证供应商提供从未重复的 IP。

静态代理和原充值订单只读复查仅尝试一次；无效配置、内核缺失、回执授权失败、关闭无法确认或本人验证挑战不作为坏 IP 自动重试。准备期间不注入账号 Cookie、不输入账号资料或主动提交业务，拦截登录／注册表单提交、建单和付款写入，允许官网匿名页面正常初始化；准备成功后复用该页面，业务流程只调用一次。登录、注册提交、建单或付款开始后不换 IP，也不重放业务。恢复同一注册任务使用原窗口、代理和指纹；密码与 MFA 核验使用同一浏览器的新 Context，不继承已登录 Cookie。

充值只读准备阶段有 1200 秒最终进程保护；成功进入业务阶段后重新启用原 900 秒保护，不把换 IP 的耗时计入原业务预算。取消会停止后续提取并关闭当前失败窗口。进度使用独立 `proxy_attempt`、`proxy_attempt_limit`、`proxy_wait_seconds`，不改变已有登录加载的 `session_*` 范围或付款确认规则。

每次启动由 Camoufox 生成原生环境。启动后在空白页读取 UA、平台、硬件并发、语言、屏幕、Canvas 和 WebGL 的摘要；当前 Worker 中摘要重复时关闭并重新生成，最多三次。注册任务同时通过现有 `browserProfileId` 检查历史注册任务的重复摘要。摘要不包含账号、代理出口或授权信息。这证明当前采样参数的差异，不等于所有网站可观察属性均不重复。

2026-10-05 隔离候选将注册与充值拆为 `auto-registration` 和 `auto-recharge` 两个独立进程，各自拥有任务槽、浏览器、临时内存盘和控制网络；复用同一 Worker 镜像。未结束的原注册窗口只阻止另一笔注册，不占用充值。充值取消、超时退出或重启不会关闭注册窗口。同类任务继续串行。注册完成或取消时关闭原窗口；失败保留原窗口供继续。所属 Worker 重启后不保留 Cookie，也不假装恢复原窗口；系统要求先人工核对官网账号，避免重复注册。已使用比特的旧注册任务不会自动换成新窗口。

拆分尚未上线。切换旧共用执行器前继续检查活跃注册与保留窗口，不能为发布取消原任务；现有内存中的窗口不能迁移到新进程，须待原任务结束并确认释放窗口后切换。

## 内核和依赖

- Python 包固定 `camoufox==0.5.6`，沿用 `playwright==1.62.0`。
- 内核固定 `152.0.4-beta.30`，服务器为 Linux x86_64。
- Docker 构建时下载官方版本文件，并校验 SHA-256；版本、URL 和校验值集中在 `install_fingerprint_browser.py`。
- 运行路径为 `/opt/camoufox/camoufox`。没有运行时内核、GeoIP 或默认扩展下载，没有普通 Chromium 回退。
- 浏览器保持现有只读容器、临时内存盘、非 root 用户和内存限制。已有 Chromium 安装仍用于旧执行器兼容；当前注册与服务器充值入口使用 Camoufox。
- 充值使用 `AUTO_RECHARGE_WORKER_URL`，注册使用新增 `AUTO_REGISTRATION_WORKER_URL`（默认 `http://auto-registration:8051`），不回退充值地址。两服务复用 `AUTO_RECHARGE_WORKER_TOKEN` 和回调地址；`AUTO_RECHARGE_WORKER_ROLE` 固定为 `recharge` 或 `registration`，拒绝另一类业务路由。`AUTO_RECHARGE_WORKER_IMAGE` 仅配置本地共享镜像名称，生产发布仍将两服务固定到同一不可变镜像。

macOS 本地验收安装器支持官方 ARM64 文件，并把官方 `properties.json` 复制到库显式路径读取位置。自动注册与服务器充值在系统执行器内操作，不要求管理员安装比特浏览器或配置本机连接器；自动充值的本机模式仍遵循既有比特浏览器设置。

官方资料：[使用说明](https://camoufox.com/python/usage/)、[安装说明](https://camoufox.com/python/installation/)、[固定版本发行页](https://github.com/daijro/camoufox/releases/tag/v152.0.4-beta.30)。Python 包使用 MIT 许可证；修改 Firefox 的原生内核遵循上游许可证，分发时保留官方许可与源码入口。

## 任务与数据保护

API 复用管理员认证、加密字段与事务审计。新增私网注册健康、派发、状态、验证码、继续与取消端点，不向管理端返回密码、MFA 密钥或任务授权。写命令仅发送一次，丢失响应后只查询原尝试收据；无法确认时保留原任务与输入，不重新创建账号。邮件读取限定当前任务、尝试、步骤、授权与有效邮箱，确认接收后才消费邮件编号。

取消时先撤销任务授权，再核实原尝试已结束且窗口关闭。关闭结果不明确时保留“待继续”和“重试关闭”入口，阻止继续或重新启动；窗口确认关闭后才标为已取消并释放执行队列。发布切换同时检查充值任务、注册任务和未关闭的注册窗口。

注册使用既有账号保存服务，按官网身份、密码和 MFA 的独立核验记录结果；不凭本地执行回执冒充官网注册成功。仅核实身份时可以保存账号并标明安全资料未完成。本人验证或电话验证暂停，由管理员处理；本轮没有新增远程桌面入口。

充值保留既有金额、币种、账号、国家与付款确认保护。此次同时整合充值窗口的代理提取、出口观测、登录准备与清理超时修复，清理失败不进入付款，并保留原始失败。没有新增或修改付款规则、数据表、字段、迁移或生产记录。

## 本地证据与发布边界

本地指纹切换证据位于 `.runtime/registration-builtin-browser-20261002/RESULT.md`，后续 20 秒／10 次代理重试增量见 `.runtime/proxy-auto-retry-20261003/RESULT.md`。实际原生内核验收包括 Linux/amd64 只读断网容器的连续启动和相同任务核验环境，以及 macOS 原生内核下全部请求本地拦截的注册、密码与 MFA 流程。模拟官网和本地账号事务不能证明真实网站注册或付款成功。

本次候选已按用户授权在最新主线基础上统一整合，保留自动充值的比特本机充值与仅登录入口。检查、远端 CI 和生产结果分别记录在主项目 `.deploy/workspace-release-20261003/RESULT.md`；这些步骤实际完成前不表示已经发布。更新 Worker 后仍需核对真实代理、官网与人工验证可操作性，模拟验收不能代替真实业务结果。
