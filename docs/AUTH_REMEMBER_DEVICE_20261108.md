# 登录保持与设备管理

本次修复独立新版的固定八小时到期问题，不修改业务数据库、密码算法或自动充值核心。

- 登录页的“在此设备保持登录”由用户主动勾选；未勾选仍为八小时固定有效期。
- 勾选后：首次有效期30天，实际输入或点击时续期至最后操作后30天，最晚首次登录后90天重新验证。
- 页面计时器、自动查询、SSE、切回标签页和合成事件均不续期。受信任的键盘/指针操作包括同源嵌入页，客户端两分钟内合并活动请求。
- 公网会话继续使用持久化私有目录、摘要文件名和 `__Host-` / Secure / HttpOnly / SameSite=Strict Cookie；不保存明文密码或在浏览器存储令牌。
- 续期原子替换私有会话文件；退出删除会话，后续活动请求不能恢复它。
- 原有八小时会话继续原期限，保留更新后的登录；不会自动把未选择的旧设备延长到90天。
- 我的账号显示本账号的登录设备、当前设备、普通/保持登录、最近使用和到期时间，可确认后单独退出。
- 其他账号无法通过设备标识查看或退出本账号会话。修改密码、角色或启用状态继续通过账号会话版本使全部相关设备即时失效。
- 临时网络、5xx、账号文件或会话目录不可读取时显示重连/重试，不把服务错误当作身份失效。401 才按登录失效处理，403 保留为操作权限错误。
- 失效原因以受控中文说明展示；Cookie 已被浏览器自然清除时无法凭空判定原因，登录页保留正常登录入口。

接口：POST `/api/local/auth/activity`、GET `/api/local/auth/devices`、DELETE `/api/local/auth/devices/:id`；均复用既有身份和同源校验。删除设备写安全审计，不记录令牌、摘要、密码或原始浏览器标识。

验证：模拟时钟覆盖30天闲置、持续活动90天上限、自动查询不续期、重启、旧会话兼容、退出及撤销、跨账号/跨域拒绝、密码/角色/停用失效、私有文件和链接保护、临时存储故障。离线拦截的浏览器验收覆盖登录勾选、设备撤销确认、网络故障保留页面、到期原因、320/390/1280宽度和深浅主题。生产验证只读，不退出真实设备、不生成测试订单或付款。


## 审查问题修复

- 新登录改用版本化的 `__Host-id_session_v2` Cookie（本机为 `id_local_session_v2`）。保持登录的浏览器Cookie只在登录时设置，最多保留90天；访问资格仍由服务端30天闲置期限及90天绝对上限控制，浏览器保留Cookie不等于登录有效。普通登录仍为8小时。
- 既有Cookie继续使用原名称和原会话，不强制重新登录；旧保持登录会话继续滚动续期。新Cookie存在时不会回退到旧身份，即使新Cookie无效或重复。退出同时撤销并清除两种Cookie对应的会话。旧续期响应即使晚到，也无法覆盖新Cookie。
- SSE使用严格的认证读取：存储故障抛给事件通道，只关闭连接并重连；真正过期或撤销仍发送身份失效事件。普通HTTP继续返回临时服务错误。
- 重连提示随当前模态抽屉或确认框迁移，关闭后回到仍打开的抽屉或页面；保留未保存输入，按钮不处于模态背景的不可交互区域。
- 新增真实Cookie的双标签页延迟回归，覆盖新会话及旧会话迁移；真实认证模块与推送模块组合回归覆盖账户文件和会话目录故障、通知和心跳两条路径；抽屉/确认框内直接重试包含鼠标、键盘及输入保留。
