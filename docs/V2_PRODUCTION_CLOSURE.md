# V2 AWS 生产闭环

## 当前基线

- 生产应用运行于 AWS EC2，使用 Caddy、Vue、NestJS 和 MySQL 8.4。
- 认证只使用本地 JWT、活跃会话、MFA 和 IP 白名单。
- 数据库备份保存在 EC2 本地和私有 S3。
- 汇率定时任务在 AWS API 进程内运行。
- 管理端通过同源 `/api` 访问 API，并使用精确 scope version 校验刷新数据。

## 2026-08-27 迁移证据

- 旧 AWS MySQL 在迁移前已备份到本机和 S3。
- 来源数据已导入全新 MySQL 库，未对旧 AWS 库执行覆盖导入。
- 最终迁移共 59 张业务表、96,027 行。
- 所有迁移表精确行数一致，142 条外键约束无孤儿记录。
- 生产 API 确认连接新 MySQL 库，认证模式为 `local`。
- 首页、live/ready、登录、`auth/me`、订单、续费、账号、客户、开通、余额、汇率和登出全部通过。
- 只读巡检账号的财务写入返回 403，说明最小权限门禁生效。

## 正式投产前人工验收

1. 按管理员、财务、运营和普通员工复核真实权限矩阵。
2. 使用真实业务数据完成加卡、订单、退款、续费和财务冲销闭环。
3. 验证手机窄屏、分页首页/末页、空状态和长时间页面恢复。
4. 执行一次 S3 备份的隔离 MySQL 恢复演练。
5. 确认 CloudWatch/系统日志中无持续 5xx、连接池耗尽或汇率任务重复执行。

## 停止条件

出现以下任一情况时停止写入并回滚应用：

- 数据库行数或外键校验异常。
- 金额精度、账户余额或财务借贷不平。
- 登录、MFA、会话撤销或权限隔离失效。
- 新版会将旧数据库数据写回当前库。
- 备份无法恢复或恢复结果未验证。
