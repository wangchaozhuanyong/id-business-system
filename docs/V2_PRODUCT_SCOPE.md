# ID 业务管理系统产品范围

## 1. 页面

| 分组     | 页面     | 核心能力                                                           |
| -------- | -------- | ------------------------------------------------------------------ |
| 工作台   | 续费操作 | 到期预警、筛选、手工续费录单                                       |
| 工作台   | 订单录入 | 客户选择、快捷新增、自动/手动选择合格 ID、预计利润与收款建议、结算 |
| 工作台   | 加卡     | 手工录入卡号、面值、汇率和供应商                                   |
| ID 管理  | ID 录入  | ID 资料、余额成本、状态、敏感资料                                  |
| 订单管理 | 订单管理 | 查询、修改、退款、取消、软删除                                     |
| 客户管理 | 客户记录 | 客户资料、来源、标签和状态                                         |
| 记录中心 | 加卡记录 | 加卡与反向流水                                                     |
| 记录中心 | 开通记录 | 业务开通与到期记录                                                 |
| 汇率管理 | 汇率记录 | 公开报价采集、人工记录与设置                                       |
| 业务设置 | 选项设置 | 国家、业务、供应商和结算平台                                       |

仪表盘暂不开发。

## 2. 业务规则

- 所有业务操作由内部员工完成。
- 加卡只允许手工录入卡号、面值、汇率和供应商。
- 续费只完成系统内订单、余额、成本和开通台账。
- 汇率采集是唯一允许的联网业务采集。
- 订单匹配只能使用同国家、状态正常、余额足够且未占用的 ID。
- 金额使用 Decimal，利润由服务端计算。
- ID 密码、密保、手机号、完整卡号等敏感字段加密保存并默认脱敏。
- 删除采用软删除；不可变账务通过反向流水纠正。

## 3. 续费预警

- 全局提前预警默认 3 天，可设置 1–365 天。
- 默认列表和右上角提醒显示预警窗口内即将到期及已到期记录。
- 日期范围允许查看任意到期时间。
- 7 天以后的记录只能查看，不能执行续费。
- 提醒不是未读消息，不触发外部发送。

## 4. 快捷新增客户

订单录入选择客户时可打开右侧新增客户抽屉：

- 不跳转页面。
- 复用正式客户创建接口、权限、校验与审计。
- 保存后刷新客户选项并自动选中新客户。
- 保存失败保留表单内容。

## 5. 明确不在范围

- 外部消息推送与消息渠道配置
- 兑换码商城、自动发货和售后补发
- 平台 OAuth、平台订单同步和发货回传
- Apple 官网登录、验证码、设备确认和自动操作
- 图片文字识别
- 数据中心、运维监控和网站内容管理
- 公开注册

新增范围必须由用户明确授权后写入本文件。
