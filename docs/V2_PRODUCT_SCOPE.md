# ID 业务管理系统产品范围

| 工作台   | 订单录入   | 客户选择、快捷新增、ID 保留/卖出、自动/手动匹配、利润与收款建议、结算 |
| 工作台   | 加卡       | 手工录入卡号、面值、汇率和供应商                                      |

## 2. 业务规则

- 所有业务操作由内部员工完成。
- 加卡只允许手工录入卡号、面值、汇率和供应商。
- 加卡记录标记“被赎回”时可选择同时永久报损该 ID；未选择时只损失当前礼品卡，选择后先扣除
  当前礼品卡，再将 ID 的剩余余额与余额人民币成本报损清零，两项操作原子完成。
- 续费只完成系统内订单、余额、成本和开通台账。
- 汇率采集是唯一允许的联网业务采集。
- 订单匹配只能使用同国家、状态正常、余额足够、未占用且未卖出的 ID。
- “保留 ID”不计 ID 购买成本；“卖出 ID”保存购买成本快照并停止匹配、加卡、余额调整和续费。
- 取消未完成的卖出订单会自动收回 ID；退款默认保持已卖出，只有明确确认“ID 已收回”才恢复可用。
- ID 报损会永久冻结资料并将余额与余额人民币成本清零；亏损金额只取余额人民币成本，不重复计入
  ID 购买成本。
- 已卖出 ID 允许报损并保留原销售关系；已报损 ID 不允许恢复、编辑、删除、加卡、调余额、匹配、
  扣款或续费。
- 金额使用 4 位 Decimal；利润与建议收款均按“余额成本 + 实际计入的 ID 成本 + 平台手续费”计算。
- ID 密码、密保、手机号、完整卡号等敏感字段加密保存并默认脱敏。
- 删除采用软删除；不可变账务通过反向流水纠正。

## 3. 续费预警

- 全局提前预警默认 3 天，可设置 1–365 天。
- 默认列表和右上角提醒显示预警窗口内即将到期及已到期记录。
- 日期范围允许查看任意到期时间。
- 7 天以后的记录只能查看，不能执行续费。
- 提醒不是未读消息，不触发外部发送。

## 4. 快捷新增客户

订单录入选择客户时可打开右侧新增客户抽屉：

- 不跳转页面。
- 复用正式客户创建接口、权限、校验与审计。
- 保存后刷新客户选项并自动选中新客户。
- 保存失败保留表单内容。

## 5. 明确不在范围

- 外部消息推送与消息渠道配置
- 兑换码商城、自动发货和售后补发
- 平台 OAuth、平台订单同步和发货回传
- Apple 官网登录、验证码、设备确认和自动操作
- 图片文字识别
- 数据中心、运维监控和网站内容管理
- 公开注册

新增范围必须由用户明确授权后写入本文件。
