## 修复结果

1. **原订单核对能执行新租约**：线上适配器使用业务任务、租约编号和版本生成稳定的本机执行编号。
   同一租约继续命中完成缓存；新租约创建新的执行实例，回调仍绑定原业务任务和原租约。
   原任务、设备归属、只读核对和重复付款保护继续由服务器校验，不新增业务订单。
2. **核实成功推进原账单**：比特任务的账单从“结果不明”更新为“成功”前，核对原付款标识、实际 Decimal 金额、
   币种、任务、卡片和套餐。仅更新原记录状态并写审计，重复核对不新增账单；迟到失败或不明回执不降级成功事实。
   金额缺失或绑定不符时拒绝推进。其他通道沿用原行为。
3. **后台安装失败可重试**：已有同网站、格式有效的设备凭据时，先通过只读接口验证原身份，成功后复用原文件恢复后台配置。
   不重复兑换已消耗的配对文件，不覆盖已有凭据；凭据失效、其他网站、其他项目或助手忙碌时停止切换。
   Mac 和 Windows 的注册失败后重试路径均有合成回归。

已绑定电脑再次运行安装入口属于“恢复原后台启动”，不会消耗新配对文件或自动换绑其他电脑。
更换电脑日常仍在网站选择；更换设备身份不由恢复步骤自动完成。
