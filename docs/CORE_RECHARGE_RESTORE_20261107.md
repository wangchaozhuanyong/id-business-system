## 恢复步骤与实现

1. **原版全量恢复。** `prepare.mjs` 只归档、解包固定提交，不再改写 `server.js`、`index.js`、`mysql-store.js`、`payment-retry.js`，也不再将桥接模块写入原版服务。逐个核对全部 Git 追踪文件的内容、类型及执行权限，覆盖调度、存储、浏览器、Checkout、Session、换卡及依赖锁；准备和运行预检都拒绝被改写的副本。附加版本标记不是源码一致性的替代证据。
2. **外围身份接入。** 新增独立 `native-adapter.mjs`，保留统一员工会话和服务签名。管理调用通过原版已有 Bearer 接口；签名沿用原版导出函数，仅查询 `admin_password_version`，不读取密码 hash 或 TOTP secret。原生短期令牌仅在服务器内存使用，管理会话接口仍返回外围会话视图，不向网页暴露原生 token。管理权限和敏感资料权限继续在外围校验。
3. **商城跟随原版。** worker 只按原版契约提交 `cdk + session`，不再要求商城专用响应头、不传 `expectedPlan`，不附加套餐类型、换卡、执行次数或供应商限制。兑换码验证、实际套餐、地区、付款方式、换卡和重试由原版决定。商城外围保留身份、来源、任务归属和防重复提交，不能据轮询失败再次充值。
4. **采集与写表隔离。** 采集只查询已经创建的原任务。新增签名内网进度回执，只传任务编号和固定阶段；心跳只续外围观察租约，不调整原版执行期限。采集或订单写表失败不取消、标记原任务失败或重新提交付款。原有订单采集客户端继续禁止调用充值执行接口，未知结果保留原任务核对。
5. **客户数据边界。** 客户任务视图仅含 `id/plan/status/stage/message/updatedAt` 和创建时必要的查询凭证；不透传原始响应、完整卡号、有效期、安全码、手机号、Session、日志、验证码元资料、截图、录像或支付链接。管理接口、原版 WebSocket 不开放给客户；商店后端凭据不能进入浏览器。
6. **分开核验和发布。** 开发阶段完成源码修改、无数据库测试与静态检查。用户随后明确授权本次提交、推送、合并 main、正式发布及只清理本次安全临时资源。真实付款、测试业务记录、密钥轮换、破坏性操作和生产回滚仍不包含；正式结果以发布回执为准。

## 运行配套和发布前条件

- `runtime.mjs start/start-production` 现在只启动外围回环适配器，不会隐式在宿主机启动原版的全网监听端口。网站和商城仍连接外围适配器地址。
- 原版服务单独按原版方式运行于经过核验的私网容器。`ID_RECHARGE_NATIVE_URL` 指向该服务在宿主机的回环映射，`ID_RECHARGE_NATIVE_CONTAINER` 指定实际容器。启动外围前只读核对 Docker 的真实 NetworkMode、TCP 映射及运行状态，拒绝 host 网络、共享其他容器网络、外网映射、错误端口、UDP 冒充 TCP、停止容器和不可核验状态。
- 开发阶段未启动本机容器。**现有生产部署不能只替换源码后重启。** 需先准备并核验私网服务、原版数据库连通、端口映射、原有浏览器设置及全部运行环境。原版没有 HOST 选项，禁止用一个环境布尔值假装已经隔离。
- 已有有效 `ADMIN_TOKEN_SECRET` 原样保留；原配置缺失时，原版与外围使用既有桥接密钥按独立用途 HMAC 派生同一内存签名值，不新增密钥文件或轮换现有密钥。运行设置通过平台加密 credential 和私有管道传递，`.env.example` 只有占位值；本机备份与发布日志不包含秘密。
- 原版启动会按原行为初始化数据库、重置及回收资产锁。本轮不修改这些行为。切换前必须在外围核对全部活动与未决付款任务、资产占用和可恢复备份；不安全时停止切换。原运行锁与只读预检保留为外部启动配套，不能让两套执行器同时连接同一正式库。
- 正式 native 进程直接执行原版 `node server.js`，不使用 `--import` 预加载外围锁监控。宿主 flock、唯一容器名和端口防止重复启动；数据库只读预检在启动前独立完成。辅助数据库连接中断不能杀死运行中的充值进程。
- native 容器与 adapter 使用独立 systemd 服务；adapter 停机不停止原版任务。宿主实际检查网络后注入最长 30 秒的签名证明，adapter 不挂载 Docker socket。新镜像沿用原版可选 Python 配套开关和既有 Node 运行版本；精确持久化截图、录像和导出输出，不挂载混合源码。运行配套见 `deploy/recharge-core/README.md`。
- 本机源码核验、容器端口核验、服务器实际运行文件核验和真实付款验收是独立证据。发布时必须核对真正运行的原版文件与锁守卫，不能只根据镜像标签或本地目录宣称已经恢复。
