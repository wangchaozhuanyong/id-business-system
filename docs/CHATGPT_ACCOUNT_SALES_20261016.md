# ChatGPT 账号出售状态交付记录

## 范围

账号增加未出售／已出售与当前标记时间，顶部增加已出售页签。只有 `registered=true` 可以标记已出售；人工标记注册但资料待补齐也允许。出售后退出待用清单，充值续费条件沿用现状。删除与恢复不改变出售历史。

现有修改接口携带账号版本，在事务内完成资格、并发校验、更新和脱敏审计；重复标记不刷新出售时间。改回未出售清空当前时间，历史保留在审计中。没有新增买家、售价、收款或付款操作。
