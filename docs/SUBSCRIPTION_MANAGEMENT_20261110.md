# 订阅账号管理

## 职责与入口

- 邮箱管理登记邮箱及其使用情况；账号管理登记公司产品账号、库存使用和实际操作人。GPT 的注册地点只登记国家。
- 订单管理保留每笔订单和当时的人员快照；订阅管理按 GPT、Claude、Gemini、Grok 分页，组合读取订单、账号和邮箱资料，查看每个账号的订阅状态及订单历史。
- 原 `#/data-management/claude-google-subscriptions` 跳转到 `#/subscriptions/claude`。Claude 支持已关联的不同邮箱类型，保留原来的个人复制后缀及短、完整两种复制格式。
- Claude 账号页提供历史账号入库；Claude 订阅页提供已开通的历史资料入库。已开通的 `claudeHistory` 进入账号管理的「已使用」并出现在订阅管理，保留原开通和到期日期。历史入库不生成订单。历史入库沿用既有预检：同邮箱已有不同的账号或客户订单时需先核对，不覆盖原资料。

## 统计与核对

账号按产品和可确认的账号标识汇总；无法确认标识的订单各自保留在待核对，不按空账号合并。客户缺失、客户或库存关联冲突时待核对；已确认开通的订阅允许设置归属人；未开通的账号只记录操作人。已保存订单保留自己的归属快照。Grok 保留 X 账号身份及不同订阅系列，同一账号多次续费在详情中保留独立订单。同一账号的不同系列可分别计入有效、已过期等状态并被对应筛选找到；全部账号数量按账号去重，因此各状态数量之和可能大于全部账号数。

订阅成功依据为 Gemini／Grok 订单中已确认的权益、可信自动充值完成时间、管理员对 GPT／Claude 已付款订单的开通确认，或 Claude 历史入库中的已开通记录。仅有付款或撤单状态不能证明有效，进入待核对；Gemini／Grok 的待确认权益继续从订阅详情进入原订单核对。有效期不完整或未来才开始也待核对；超过到期时间为已过期，明确结束的已确认订阅为已终止。退款本身不自动终止订阅。

订阅剩余天数与 Claude 查询码状态和剩余天数分别计算。列表只返回资料状态。点击复制后按确认的账号、邮箱关联读取资料，缺失资料在操作结果提示，存在关联冲突时拒绝复制。可用查询码才加入 Claude 复制内容。已终止订阅仅提供账号标识及适用的个人后缀。

Claude 养号按注册时间算至当前时间，默认门槛为 72 小时，在 Claude 账号的「本表设置」中可调整。达到门槛且账号及库存状态符合要求时可提取。历史账号缺原注册时间时待核对，历史登记的「养号中」标签保留原登记结果。

## 数据和接口

`POST /api/local/subscriptions/{list,account,lookup,copy,confirm,owner}` 只允许管理员和超级管理员经同源请求使用。读取、复制、确认开通及归属变更写审计，审计不包含凭据原文。确认和归属写入沿用事务、文档版本和命令去重；开通确认关联订单快照，订单关键资料变化后需重新核实。

业务归属和开通确认保存在现有加密文档机制的 `subscription-management` 域，并纳入本地备份恢复域清单，不新增 SQL 表或迁移。新订单关联有明确归属的账号时带入该归属，录单人由当前操作身份独立记录；原订单归属快照不回写。账号归属与客户或库存关联不一致时需先核对，不能通过拼接凭据消除冲突。

## 验证边界

本地使用合成资料验证业务规则及浏览器交互。项目 CI 使用隔离的 SQLite 夹具验证归属版本竞争、库存续费继承、失败回滚、加密快照恢复和重试回执。正式网站验收只读取页面和资源。
