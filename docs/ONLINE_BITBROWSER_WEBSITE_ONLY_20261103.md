## 日常怎样充值

两台电脑分别完成一次性接入后，日常只操作网站：

1. 在“线上代充 → 系统配置”的“比特浏览器执行”中选择“指定执行电脑”，选择 Mac 或 Windows，保存配置。
2. 客户在原充值页面提交兑换码和完整授权 JSON；系统按兑换码确定套餐，创建任务并绑定当时选定的电脑。
3. 所选电脑开机并登录，后台助手及比特浏览器可用时自动领取，完成登录、核对账号与报价。
4. “核对金额后付款”模式在网站确认当前报价后继续；“全自动付款”按已保存的套餐、币种和金额上限核验后继续。
5. 网站显示进度和结果；核实成功后核销兑换码并记账。结果不明确时保留原任务等待核对。

切换电脑只影响之后受理的任务，原任务继续绑定原电脑。所选电脑离线、休眠或比特未就绪时任务排队，
不会自动改派另一台；全局同时只执行一笔线上比特充值。关闭网站页面不影响后台助手。
登录官网遇到人工验证时仍需在对应执行电脑处理，不能保证所有外部验证都在网站完成。

## 每台电脑只需首次设置

本次提供的是已有充值助手的一次性后台设置入口，不是独立的完整助手安装包。
需要在每台执行电脑准备包含本次代码的助手文件夹、Python 3.11 或以上版本，以及已安装的比特浏览器。
不需要本地网站、数据库或 Docker。

1. 在网站“执行电脑”填写可区分的名称，例如“办公室 Mac”“充值 Windows”，生成并下载各自的配对文件。
   配对文件单次有效、10 分钟过期；不要把 Mac 的配对文件交给 Windows 使用。
2. 在对应电脑的“比特接口设置”填写该电脑自己的 Local API 地址、密钥、已存在的分组与标签并保存。
   比特端应启用 Local API，默认地址为 `http://127.0.0.1:54345`；配置不完整时助手不能就绪。
3. 下载对应系统的“一次性设置入口”ZIP，解压后双击。选择新版助手所在的项目文件夹，再选择本台电脑的配对文件。
   首次可能下载原助手锁定版本的 Python 依赖；准备失败时保留原助手和任务。
4. 回网站刷新，确认对应电脑“在线，可领取任务”，再在“指定执行电脑”选择它并保存。
5. 此后登录电脑自动后台运行；保持电脑唤醒和比特浏览器可用，日常不必开终端或重复启动助手。

Mac 使用当前用户的 LaunchAgent，复用已有助手的服务标识、端口和本机访问配置；Windows 使用当前登录用户的
Task Scheduler，不保存用户登录密码，设置为单实例及登录启动。安装入口均不携带电脑凭据。
本机绑定文件位于助手项目的 `.runtime/bitbrowser-recharge-assistant/device.json`，不进入 Git。
已经绑定的电脑不会被安装入口静默覆盖；日常切换电脑直接在网站完成。
安装失败重试时，入口先验证并复用同网站的原设备凭据，恢复后台启动，不重复兑换配对文件。
已绑定电脑的安装恢复不会自动换绑其他电脑；原凭据失效时停止并提示核对。

本轮只读确认当前 Mac 已有旧助手的后台启动配置，未替换、停止、重启或换绑它。
尚未在真实 Windows 上安装或验证登录自启动；两种平台的生成配置及受控失败路径已通过合成测试。
实际接入应在后端迁移、代码发布及远端隔离数据库验证完成后进行。

## 实现和兼容

- 每台电脑独立配对、停用和保存比特连接配置；配置密钥加密保存，管理端只返回“已保存”标记。
  电脑凭据只能读取本机连接，不能用参数获取另一台电脑的密钥。
- `bitBrowserDeviceId` 保存指定电脑；任务受理时快照设备和加密连接配置，后续设置不改写原订单。
  未指定时兼容原 `primary` 电脑，原主电脑保留旧全局比特配置回退；新增电脑必须配置自己的连接。
- 新增电脑不覆盖原身份；停用一台不改变另一台凭据。所选电脑不可用时不偷偷改派。
- 修复 Python 付款状态文件与服务器校验的衔接：按原 Checkout 标识派生文件名，同时核对账号、套餐及报价。
  Windows 使用系统文件锁，POSIX 保留原文件锁，重复付款保护继续生效。
- 单次接口密钥输入不进入草稿，关闭、切换电脑、身份变化和卸载时清除；普通连接字段按电脑保留会话草稿。
  配对凭据仅在当前页面内存显示，离开或身份切换清除。

所有接口以前缀 `/api/id-business-v2/online-recharge/` 开始：

| 接口                                          | 用途                                                         |
| --------------------------------------------- | ------------------------------------------------------------ |
| `GET admin/bitbrowser/devices`                | 多台电脑的安全状态和各自当前任务，读取权限                   |
| `GET admin/bitbrowser/device/:id/connection`  | 读取非秘密连接字段、保存状态和配置版本，读取权限             |
| `POST admin/bitbrowser/device/:id/connection` | 按版本保存指定电脑的加密连接，读取及管理权限                 |
| `POST admin/bitbrowser/device/pairing`        | 省略 `deviceId` 新增电脑，传入时重绑指定电脑，读取及管理权限 |
| `POST admin/bitbrowser/device/revoke`         | 可传 `deviceId` 停用指定电脑，读取及管理权限                 |

本轮扩展不新增表、列、migration、依赖或环境变量，沿用原配置 JSON 和上一轮设备表。
上一轮专属迁移 `20261102150000_online_recharge_bitbrowser` 仍未应用，原纯净基线不变。
发布需要同步 API、管理端、临时 CVC 服务和执行电脑助手，仍须先执行远端隔离数据库验证。
