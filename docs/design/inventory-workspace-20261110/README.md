## 页面行为

- 管理快捷只保留「账号提取」「邮箱提取」「提取与归还」「比特登录」。
- 账号提取左侧按 GPT、Claude、苹果 ID、Gemini、Grok 录入或批量导入，右侧提取可用账号。苹果 ID 仍只录资料。
- 邮箱提取左侧复用谷歌邮箱与当前账号有权使用的隐藏邮箱登记，右侧提取。微软邮箱仍由独立管理页维护，没有新增提取权限。
- 内容宽度达到 960px 时两模块并排；窄屏上下排列。标签保持在控件左侧，说明放在标题右侧按钮。
- 两侧各显示最近 5 个批次，摘要按实际记录显示类型、数量、人员、时间及状态。记录区域限高且可键盘滚动，所有记录操作均可滚动到完整显示。全部导入打开原记录表并使用共享分页；批次明细、归还与用途设置沿用原功能。
- 旧 `/workspace/account-submit`、`/workspace/mail-submit` 书签分别转到对应提取工作台。旧的单条、导入与提取草稿键保持兼容。
- 成功导入后右侧库存同步更新；失败不更新库存，保留输入。左侧提交只清理相应提交快照，不清空右侧提取草稿。隐藏邮箱登记结果继续在左侧显示。
