## 原因与修复

目标路径为“数据管理 → Claude 谷歌订阅管理”与“线上代充 → ChatGPT 充值 → 银行卡池”之间的切换。此前诊断记录保留在 `.runtime/transition-diagnosis-20261110/诊断结论.md`。

原订阅页离开时清除敏感资料，返回时却连表格框架也没有渲染；超过 120ms 后，普通文档流内的加载文字把面板撑高，接口成功又整页重建。诊断中的桌面空列表依次出现 74 → 128 → 229px 高度，造成肉眼可见的塌缩和跳动。

- 从共享读取层修改加载反馈：运行中仅显示不占文档流的 3px 进度线，状态文字继续供辅助技术读取。刷新按钮状态、120ms 门槛、请求替换与结束清理保留，错误提示不受进度线样式影响。
- 订阅页始终渲染实际表头，按列表宽度与每页数量保留测量后的框架尺寸；只存尺寸，不保留已离页的账号、密码、查询码或总数。首次未取得结果时，不显示未经确认的总数。
- 成功或失败只更新列表与错误区域，不重新建立筛选表单。搜索输入、横向阅读位置和普通草稿保留；请求期间旧列表只读，失败继续显示上次成功内容。
- 分页接入既有公共分页事件，保留本模块 8／16 条每页选项。首末页及空结果维持框架高度，键盘操作在更新后仍可继续从分页区操作。
- 补齐长值控件已有的省略样式类，保留查看完整内容与复制入口。
- 离页继续清除敏感快照与旧节点，迟到响应不会覆盖新页面；身份清理同步清除尺寸记录。
