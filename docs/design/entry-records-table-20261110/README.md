## 页面行为

- 客户、租户以及 GPT、Claude Pro／Max、Gemini、Grok 订单录入共用加宽记录表。宽屏约左四右六，一条记录一行，顶部为时间筛选，底部为独立分页，不再限制只能查看最近十条。
- 表格优先展示姓名、联系方式、订阅套餐、备注、提交时间和操作；四类订单录入另在套餐后展示“支付方式”，读取每条已保存订单的实际登记值，缺失显示“—”，不跟随左侧草稿变化。客户和租户表不增加支付列。联系方式仅包含已登记渠道，不生成未填写的微信、QQ 等空项目；整组没有联系方式时不显示该列。套餐来源是当前权限内关联订单的登记内容，不将其冒充仍然有效的订阅。
- 复用公共分页，支持每页 10／20／50 条、页码与跳页。今日、昨日和日期范围均以北京时间计算，范围包含开始和结束当天；缺少录入时间的历史数据仅在全部中显示为“时间未记录”。无效范围保留原结果并显示校验提示。
- 姓名、联系方式、套餐和长备注可点击查看完整值并沿用既有复制入口。表格在区域内横向滚动，窄屏不压成逐字换行或让整页溢出；宽屏有足够空间时全部列与操作可直接看到。
- 客户行直接打开“关联订单”“历史开通业务”，租户行直接打开“关联订单”。客户／租户资料列表也保留对应直接入口。两类历史使用最大 1120px 的独立右侧抽屉及独立分页，移除客户详情中的两张窄表。开通历史仍使用原有开通证据、归属和次数口径。
- 左侧表单按自身宽度排列，足够宽时短字段两列，内容宽度不足 640px 时单列；工作区不足 1040px 时记录表移至下方。标签始终在控件左侧。
- 右侧刷新、筛选、分页及打开抽屉不会重建左侧表单或清空草稿。过滤与页码使用既有 `state.drafts`，按录入类型、产品、客户和历史种类隔离；会话清理沿用共享机制。刷新失败保留记录并可重试。
