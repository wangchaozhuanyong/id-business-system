# 全局右侧工作区 — 第四版紧凑设计

日期：2026-10-13

状态：三个视图的效果图完成，未修改业务代码、未上线。
本版根据用户最新要求，替代第三版的多行标题和话术预览卡片。

## 统一布局

右侧仍是所有业务页面共用的独立固定区块。顶部只有一行“个人工具｜在线工具｜话术文案”和整栏收起按钮，不再额外显示“快捷工作区”标题，也不在内容区重复当前页名称。

每个条目只显示一个主标题，不显示副标题、正文摘要、说明、时间或标签。右侧独立滚动，切换业务页面只更新中央内容。

## 个人工具

![个人工具效果图](./right-navigation-v4-personal.png)

每项一行：图标＋工具标题＋外链箭头。保留六个现有网址示例，底部“管理工具”入口复用原网址管理功能，支持新增、修改、删除与排序。去掉常用网站分区标题及描述，不增加新搜索功能。

## 在线工具

![在线工具效果图](./right-navigation-v4-online.png)

每项一行：图标＋工具标题＋进入箭头。保留计算 2FA 验证码、网站监控、抖音解析、邮箱查询与邮箱池、Google 表格同步、中转脚本；继续按原权限显示，不增加副标题或新业务能力。

## 话术文案

![话术文案效果图](./right-navigation-v4-copy.png)

搜索、排序、新增合为一行工具栏。

每项一行：主标题＋“复制文案”＋“更多”。不展示正文摘要或副标题，不单独显示“查看全文”按钮。

“更多”菜单保留：

- 查看全文
- 编辑文案
- 删除文案（仍需原有删除确认）

复制只复制正文，不复制标题。保留现有自定义顺序、最近修改、标题排序和搜索时的重排限制。搜索、编辑和导航状态仍遵循当前会话草稿机制。

## 尺寸及扩展

右栏展开约 352–368px，收起约 60px；桌面条目目标高度 44–48px。具体尺寸按既有公共控件与主题规则实施，效果图不作为像素测量证据。

未来增加功能时，在全局右侧组件中增加导航与内容面板；导航超出可用宽度时进入明确的“更多”入口，不换成多行标题。窄屏仍保证点击目标和操作按钮可达。

长标题在可用宽度内省略并提供完整标题提示，复制与更多始终完整可见，不被标题挤出。空状态、错误和只读状态仍需明确反馈，不因精简正常列表而删除异常状态信息。
