## 结果

- 导航仅保留「充值码提取」，旧 `workspace/my-recharge-codes` 书签兼容跳转。
- 内容宽度达到 1100px 时，左侧约三分之一为提取申请，右侧约三分之二为我的充值码；不足时上下排列。套餐和数量在可用空间内同排，标签在控件左侧。
- 左侧保留真实库存核对、提交申请、最近申请、管理员批准/驳回/重新核对。统计、原因与批次明细进入抽屉。待审核申请不会直接进入可用充值码。
- 右侧保留五个状态页签、搜索、套餐筛选、完整复制、单个归还和批量归还。主列表仅显示充值码、套餐、状态、发放时间、操作，窄容器改为卡片，完整长码换行显示。
- 两侧独立分页、加载和刷新；刷新不重建申请表单。读取失败保留最后成功列表，库存无法核对时阻止申请。成功申请的迟到响应不会清掉后来填写的内容。
- 沿用现有数据变更通知；本人新获发可用码时，右侧切换未使用、定位新批次并明确提示，可以「查看全部」退出定位。其他员工获发新码不改变当前定位，完整码仍由原接口控制查看权限。
- 列表按当前宽度与每页条数保留已测量高度，末页与空结果不自动缩小框架。申请记录可滚动查看，最后一条操作已验证可完整滚入视口；新批次对应页签在手机仍完整可见。
