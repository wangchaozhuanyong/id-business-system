# 录入工作台布局与最近记录

日期：2026-11-10。状态：代码完成，本地隔离验证完成；未提交、推送、创建 PR 或部署。

## 页面与行为

- GPT、Claude（Pro／Max）、Gemini、Grok 订单录入，以及客户和租户录入共用两栏工作台。
- 左侧短字段两列排列：银行卡号／卡序列号并排；GPT 付款方式／卡尾号、银行卡选择／类型分别成行。客户姓名／来源及各联系方式成对排列。备注和必要长内容保留通栏。
- 订单表单的相邻身份字段连贯排布，避免不同子分组造成多余空位。字段标题仍在控件左侧，必填标识、说明按钮与原有表单校验保留。
- 工作区不足 1040px 时右侧记录移至下方；表单内容不足 640px 时字段改为单列。长输入和下拉值复用完整换行读数，选择器标签自然换行，操作按钮可换行但不被压缩隐藏。
- 最近记录显示对应业务最近 10 条，按北京时间的“今日／昨日／具体日期”分组；缺少录入时间的历史数据明确显示“时间未记录”。Claude 同时覆盖 Pro 和 Max，其余产品互相隔离。
- 订单记录显示客户、套餐、提交时间及已填写联系方式；客户／租户记录显示姓名、录入时间及已有联系方式。没有填写的渠道不生成空行。详情复用现有抽屉，普通草稿保留。
- 记录区可独立滚动，桌面侧栏随页面滚动保持可见；长名单不撑长整个工作台。刷新保留上次成功内容，进度线不挤动布局；失败可以重试，左侧表单节点和输入保持不变。
