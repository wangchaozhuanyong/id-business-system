# 插件管理、Claude 邮箱接入与单行列表

本轮按用户要求实现本地源码，未提交、推送或部署；未读取真实邮箱、执行真实 OAuth 或修改线上资料。

## 导航与页面

- 左侧新增“插件管理”，子导航为“邮箱查询与邮箱池”“网站监控”“谷歌表格同步”，分别使用 `plugins/mailboxes`、`plugins/websites`、`plugins/sheets`。
- 三个入口从在线工具启动列表移出，2FA、抖音解析继续保留。新页面复用原有查询、管理、监控及表单草稿机制，使用整页宽度；员工仍可查询邮件和检测网站，邮箱池管理与谷歌表格入口沿用管理员范围。
- 邮箱管理提供搜索、类型／状态筛选和分页。邮箱、类型、备注、来源、查询码、状态、到期、最近查询、操作各占独立列，每个单元格单行，长内容省略并可查看完整标题。桌面固定操作列，窄屏在表格内横向滚动。
- 网站监控保留访问统计、访问记录、网站检测页签，数据表格单行显示。谷歌表格同步仍为待开发，本轮只迁移入口和页面。

## Claude 邮箱与授权

- 邮箱池读取时投影 Claude 账号库中的邮箱，忽略大小写去重；同邮箱已有连接时保留原编号、授权和查询码，仅增加来源标签。
- 未接入的邮箱显示“待授权”，不生成查询码、不复制 Claude 密码。投影本身不写数据库；以后新增或批量录入 Claude 账号后也会显示。库存写入同时使邮箱池读取缓存失效。
- “去授权”打开预填邮箱的连接表单。谷歌／苹果提供官方应用专用密码页面和办理说明，用户自行在官方页面操作，返回本系统填写应用专用密码并验证保存。Microsoft 复用原有 OAuth 流程。未知服务商由管理员明确选择；隐藏邮箱通过所属主邮箱授权。
- 已授权记录提供“查询”：经原有审计接口读取查询码后进入邮件查询。授权失败保留当前输入供重试，敏感凭据不进入会话草稿；离页清理查询码、邮件正文和授权输入。
- 邮箱池列表一次读取当前页的查询码，按成功读取的账号逐条保留审计。待授权、未登记查询码和读取失败分别显示，翻页或离页时清理上页查询码。
- 使用现有加密业务文档和授权接口，无新增数据库表、迁移、依赖或环境变量。邮箱池元数据响应增加 `authorizationPending` 和 `source` 展示信息，不返回密码、令牌或库存秘密。

## 邮件链接

- 收件执行器优先读取 HTML，再回退纯文本，保留邮件中验证按钮的实际链接。前端只重建安全链接，移除脚本、图片、表单及其他主动内容，不执行邮件 HTML。
- 验证码跨 HTML 标签提取，脚本与样式内容不作为验证码来源；复制及原有取信限制保留。

## 验证与边界

- 168 项前端单元检查通过；邮箱投影、去重、授权失败／成功及 HTML 验证码提取专项通过。
- Python 模拟 IMAP 验证 HTML-only、multipart 邮件的链接保留及只读 BODY.PEEK，未连接真实服务商。
- 插件页面离线浏览器专项覆盖模拟授权失败重试、授权后合并、取码查询、安全链接实际新窗口点击、六档宽度与深浅主题、网站统计与检测及草稿恢复。
- 共享布局、列表边界和手机导航 26 项回归通过。2,003 条隔离邮箱列表已验证分页、首末页、空结果、过滤、复制、操作浮层及失败重试。
- 浏览器请求全部拦截为合成数据；未启动网站、Docker 或数据库。截图归本项目 `.runtime/plugin-management-20261107/`。
- 真实服务商授权、实际验证码邮件和真实站点统计仍需人工联调；谷歌表格同步保持待开发。
