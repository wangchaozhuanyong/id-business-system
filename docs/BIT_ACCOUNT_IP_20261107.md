# 比特账号连接与执行 IP 分离

比特登录先选择当前电脑／主账号或子账号的连接，再选择执行 IP。网站不切换比特客户端身份；新电脑首次需登录客户端、启用本地接口、填写对应密钥并检测分组与标签。

IP 普通录入仅填写备注名称、动态住宅／静态住宅／移动类型和代理信息；国家、协议及连接方式自动识别，可在高级设置中手动指定。执行不再另选国家；国家从选定 IP 读取。新增失败保留当前输入，成功选中新 IP。连接配置不依赖 IP 列表，已有连接和历史代理资料保留。

本机接口密钥提供眼睛按钮，默认隐藏，切换连接、页面隐藏或离开时恢复隐藏。代理凭据不进入草稿、列表响应或审计；普通元资料和选择沿用现有会话草稿桥接。

`/api/local/bitbrowser-proxies` 复用既有管理员与同源校验。GET 返回当前操作人的版本和摘要，PUT 按版本新增，POST 按编号与版本取用并写审计。数据复用已有加密文档存储，无新增 SQL 表、迁移、依赖或环境变量。正式备份继续覆盖已有业务库和密钥，新增代理不会改写原连接。

同会话原窗口仍按账号和本机接口凭据隔离。换 IP 时先确认原窗口已关闭，只更新网络字段并回读，不更换窗口编号、Cookie 或指纹；结果不能核实时停止。

验证使用合成资料，未执行真实账号登录、代理提取、付款或通知。专项单元测试、12 组宽窄屏深浅主题离线页面与共享布局通过；SQLite 持久化与接口回归由受保护 PR 的远端隔离 CI 执行。正式发布、当前提交与线上只读验收以发布回执为准，不以本文预先声明完成。

## 页面整理与 IP 资料库（后续修订）

- 登录页按选择比特账号、选择执行 IP、填写登录资料分为三个区域；连接设置默认收起，新增连接时展开。说明进入标题右侧的共享说明浮层。
- IP 资料库提供名称／国家／类型／连接方式／地址摘要表格，支持搜索、类型筛选、排序、分页、使用与编辑；保存后选中 IP 并返回登录页。手机表格内部滚动、操作列保持可见。
- 编辑沿用同一 PUT 接口，新增可选 `id`。留空代理链接保留原密文对应资料；切换方式或协议必须填写新链接。使用既有版本检查、按用户隔离和审计，无新数据库表或迁移，不提供删除入口。
- 账号连接新增可选 `accountName` 标记，和原有 `name`（电脑／连接备注）分开。旧客户端不传时保留已有账号标记；没有标记的旧连接显示“账号待确认”。名称不代表自动验证或切换比特客户端身份，同一本机接口下的多个旧配置不能凭 IP 名称推断属于不同账号。
- 新增／编辑 IP 的非敏感字段、列表筛选／页码／页签复用宿主会话草稿；代理秘密不进入草稿。失败保留输入，409 后先显示最新摘要并由用户再次确认保存，保存中阻止关闭和重复提交。
- 验证：`test/bitbrowser-account-ip.browser.mjs` 离线覆盖 12 组宽度／主题、空与跨页列表、固定操作列、编辑留空链接、保存失败重试及执行参数；共享布局测试 8 项。实际数据隔离、版本与密文测试在远端 CI 的隔离数据库执行，不连接生产测试。

## 代理录入简化与本机检测

普通新增／编辑只显示备注名称、IP 类型、代理链接。支持购买平台直接生成的 `账号:密码@主机:端口`、`主机:端口:账号:密码` 和完整代理 URL；高级设置默认收起，可选协议、连接方式和中文国家。国家不再必填，检测后自动带入；未识别国家不会阻止授权 JSON 登录。

“测试代理”使用所选本机连接的密钥直连比特 `/checkagent`，按照[比特官方接口](https://doc.bitbrowser.net/api-docs/browser-profiles#proxy-detection-api-can-be-used-to-query-proxy-information-and-check-the-availability-of-proxies)读取成功结果与有效出口 IP。没有协议前缀的原始地址按 SOCKS5、HTTP 顺序识别；原始地址保存时自动完成识别。标准完整 URL 可直接保存。HTTPS 提取链接测试时由当前电脑读取第一条代理，再交给比特检测；受跨域或提取格式限制时明确报告未完成，实际打开窗口仍沿用旧版的动态提取流程。检测不创建或启动窗口、不导入授权，也不触发付款。

测试显示出口 IP、国家及当前电脑的检测耗时；不把格式正确或接口外层 success 当作代理可用。列表也可直接测试已保存记录。保存和执行共享同一解析器，主机、端口、账号密码自动写入比特窗口；保留固定版本 e51dd9c9 的仅登录流程。选中代理即按独立的网络配置处理，未检测国家时也能保留原窗口并更换网络，不借用国家字段控制窗口复用。

继续使用原接口、加密文档及审计；countryCode 可为空，不新增表、迁移、依赖或环境变量。旧记录完整保留。普通元资料经宿主草稿白名单保留，代理链接、接口密钥和授权 JSON 不进入草稿。探测结果只在页面内保留脱敏摘要，连接资料改变后重新检测。
