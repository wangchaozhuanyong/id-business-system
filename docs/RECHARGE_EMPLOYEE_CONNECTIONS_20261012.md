## 实际行为

- 每位员工管理员独立保存具名连接配置。原有设置保留为“原连接配置”；新配置分别保存加密的比特接口及助手密钥、代理与窗口参数、分组和标签。新增配置必须填写自己的接口秘密，不继承旧密钥。
- 不同员工在不同电脑、使用不同助手和官网账号时可以同时执行；每位员工同时一笔自动任务，同一助手依次执行。数据库只在短暂记账事务中保留原锁与 Serializable 隔离。
- 建任务前检查已知账号占用；授权 JSON 在官网身份核实后原子检查账号占用，再允许进入后续步骤。同一比特窗口也检查占用；回环地址和旧助手端口别名统一计算资源标识。
- 任务保留启动时的加密助手快照。切换配置或 API 重启后仍访问原助手；升级前运行的助手任务，在修改设置前补存原连接。列表与公开回调不返回快照和内部资源标识。
- 原窗口历史按连接资源区分；复查及历史付款处理核对原连接。原账本版本、账号归属、报价确认、持久化付款标记与一次提交限制继续保留。
- 取消和超时只处理本人的任务；结束后保留窗口。网络失败换 IP、重开同一窗口的既有功能保持。没有新增官网请求拦截、跳转阻断或 WebSocket 关闭。
- 设置草稿按配置通过公共 `useV2FormDraft` 登记。切换、关闭和切页保留输入与原版本；保存失败和迟到响应不清除后续编辑。明确的“恢复已保存配置”与关闭分开。
