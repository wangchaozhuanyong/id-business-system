## 修复结果

1. **共享页面生命周期。** 普通页面重绘当前区域；只有 ChatGPT 充值、兑换开通、比特登录显式保留已连接区域。
   查询与管理各保留一份文档，离开后隐藏，切回直接激活。取消原来整页替换和状态预览搬动 iframe 的行为。
   显式刷新仅替换目标分组，失败保留最后可用内容；同一目标的未完成普通读取合并。
2. **共享读取状态。** `IDLocalData.queries` 统一提供内存快照、规范化参数键、请求合并、强制刷新、按范围失效与清空。
   清空或失效后的旧响应不能覆盖新代次，快照按独立副本交给调用者。原有显式 `load` 仍会读取，避免刷新按钮失效。
3. **总览与工具接入。** 总览回访复用有效汇总，业务保存后失效并在下一次读取更新；部分分区失败保留其上次数据。
   网站统计与明细、邮箱池、已保存 2FA 账号的元资料、地址管理接入共享读取，关闭重开可复用结果。
   2FA 密钥和生成的验证码、邮件正文、授权 JSON、单次付款确认不进入此缓存。
4. **页面间竞态。** 命中另一组有效缓存时结束旧区域反馈，旧时间范围的迟到响应不能覆盖当前结果。
   抽屉在替换或关闭前同步发送离开通知，避免异步 `close` 事件误伤新抽屉；关闭时未完成的统计读取失效，重开重新核对。
5. **任务与身份保护。** 比特登录执行中也阻止误切页，显式停止操作仍可用。隐藏的代充管理页暂停界面轮询及计时绘制，
   不停止服务器任务或重建付款。退出、会话失效或身份变化沿用既有会话门，立即移除保留区域并清空读取快照。
6. **滚动恢复。** 首次绘制高度不足时保留原阅读目标，内容或侧栏布局稳定后补足恢复；用户操作后停止自动恢复。

缓存只存在当前标签页内存，整页刷新会重新初始化。本轮最初只实现本地保存后的范围失效及手动刷新。
随后补齐跨窗口的数据变更事件，版本比较、编辑保护和当前验收范围见
[数据变更通知](DATA_CHANGE_SYNC_20261107.md)。原有上游活动页状态轮询继续使用原频率。
没有新增浏览器持久化、依赖、业务 API、数据库表、字段或迁移。
