# 多币种换汇与订阅双手续费发布记录

本次经用户明确授权发布，包含财务账户和手工收支的 26 币种支持、收支记账的换汇录入与列表、订阅订单独立 USDT／购物网费用成本，以及依赖和检查配置修复。

## 候选范围

发布分支从远端 main 创建，保留已合并的 Pro 500 与账号资料交付功能。仅提取本任务改动；其他未提交的筛选、表单草稿、充值设置与通用界面改动保留在原工作区。工作区质量收尾记录与本发布候选的检查记录分别保留，不把原工作区的全部改动一并发布。

- 财务业务文件位于 `apps/admin/src/v2`、`apps/api/src/id-business-v2` 和共享财务类型。
- 订阅费用只记在订阅订单，两项费用不读取或分摊换汇记录；苹果卡代充保持现有账务规则。
- 本次依赖版本为 Axios 1.20.0、Mailparser 3.9.33、Nodemailer 10.0.13、Multer 2.4.0 和 ip-address 10.7.2；Vue、NestJS、Prisma 不升级。
- 保留全部备份，显式固定 ESLint 项目根并将备份目录排除出 lint 和格式扫描。

## 向前迁移

仅新增 `20261001090000_fx_subscription_costs`。既有 migration 和当前纯净基线保持原样。迁移扩展财务枚举、新增换汇表和订阅费用字段，原有订单默认 `legacy`；旧费用字段和历史利润保留，不批量转换或重算历史订单。

生产流程在迁移前要求只读财务巡检通过、没有正在执行的充值任务、镜像来源正确和新鲜备份已通过 S3 大小与 SHA256 校验。迁移后只同步新增表的应用账号权限，验证成功后切换服务。

失败时沿用发布脚本的原服务镜像恢复流程；向前 migration 不自动逆转。发布后不执行真实换汇、收费、退款或充值付款来验证页面。
