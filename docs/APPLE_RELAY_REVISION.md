# 苹果主邮箱与隐藏邮箱：功能恢复和重构边界

日期：2026-11-04。项目：ID 业务管理系统。范围：独立原型与后续正式接入契约；老系统继续线上使用。

## 1. 正确业务关系

原型此前把苹果隐藏邮箱当作普通邮箱库存录入，遗漏主邮箱连接、应用专用密码、主／子查询码、收件同步及历史邮件归属处理。这是核心流程偏离，不能只增加一个“主邮箱编号”输入框便视为解决。

正确流程：**添加 Apple 主邮箱收信连接 → 登记已经在 Apple 创建并转发到该主邮箱的隐藏邮箱 → 同步主邮箱邮件 → 根据收件身份匹配子邮箱 → 按邮箱或主／子查询码查询 → 按实际使用登记注册与库存流转。**

- 主邮箱是收信连接身份，隐藏邮箱通过稳定主邮箱编号关联。不能填写不存在的父编号；主邮箱编号不能用行序号代替。
- 主邮箱使用 Apple 邮箱应用专用密码，不是 Apple 登录密码。账号管理的 Apple ID 余额主档与这里的收信主邮箱不是同一能力，不能强制当作同一库存对象。
- 当前旧源码提供登记、批量导入、收件同步，未发现 Apple 官网自动创建隐藏地址接口。新版不增加虚假的“自动生成成功”，同步邮件也不表示自动创建或发现 Apple 端全部隐藏地址。
- 隐藏邮箱不需要独立密码、2FA、绑定电话；不能只接受 `privaterelay.appleid.com`。自动注册模块仅借用已登记地址与查询码，不创建或删除 Apple 隐藏地址。

## 4. 新页面：四个页签

采用**主邮箱、隐藏邮箱、收件记录、查询中心**四个紧凑页签。标题只在顶栏出现，说明在标题旁点击展开；搜索／筛选／操作宽屏同行，表格内部滚动，各字段独立成列；沿用最新视觉，不恢复旧布局。

### 主邮箱

- 列：主邮箱编号、地址、连接状态、主查询码、查询码到期／有效天数、子邮箱数、最近同步、最近同步错误、备注、录入人／时间、最近操作人／时间、操作。
- 新增：主邮箱、应用专用密码、备注、查询码有效天数；编辑密码留空不覆盖旧值。编号和人员不允许表单填写。
- 行操作：登记隐藏邮箱、批量导入、查看子邮箱／收件、测试、立即同步；其他放有文字的更多操作。主码重置、历史归属修复、删除分别确认和回读。

### 隐藏邮箱

- 列：子邮箱编号、地址、主邮箱编号、主邮箱地址、启用状态、库存使用状态、注册状态、买家查询码、查询码到期、收件数、最近收件、备注、来源批次、录入人／时间、最近操作人／时间、操作。
- 登记与批导先选主邮箱；从主邮箱行进入自动带入并显示对应父对象，大量主邮箱支持搜索。不能仅任意输入父编号。
- 与 `inventory.collections` 共用同一子邮箱资料，不另建普通库存副本；编辑、码重置、复制、收件、注册登记各有独立入口，不消除已使用或注册事实。

### 收件记录

- 打开时先读已入库的收件摘要及最近同步时间，随后后台同步。手动刷新同一请求内最多同时处理两个主邮箱，同一主邮箱复用正在进行的同步。
- 邮件编号、主邮箱编号、子邮箱编号、目标、匹配状态、发件人、主题、验证码、收件时间独立列。打开详情时按所属主邮箱及邮件编号单独读取纯文本正文。
- 未匹配、可匹配和歧义分别表达。重新分配及历史修复保留原记录和事件。个别邮箱读取失败时保留可用的已入库结果，并明确该邮箱的状态。

### 查询中心

- 后台可选择已登记邮箱或输入主／子码；公开查询只依据被验证的查询码范围。
- 显示目标及类型、码有效期、最后读取时间、最新验证码、收件明细；可复制、展开和重试。
- 同目标刷新失败保留成功内容并标旧，换目标隔离原内容，迟到结果不能覆盖新目标；不在 URL 传播查询码或秘密，不将验证码和授权保存为普通草稿。
- 主／子查询码按唯一目标查找，同步后按同一码重新核对绑定和有效期。隐藏邮箱列表按当前页编号读取查询码和收件统计，逐条审计集中写入一个事务。
- 发布顺序为先更新 Vendure 的收件管理接口，再更新 ID 服务及页面。

## 5. 状态与注册／提取约束

| 维度       | 含义                                               |
| ---------- | -------------------------------------------------- |
| 主邮箱连接 | 正常、禁用、授权错误、同步中；同步失败另有错误信息 |
| 子邮箱启用 | 正常或禁用，不等于是否已注册                       |
| 查询码     | 有效、到期、已重置，不等于连接成功                 |
| 库存       | 可提取、已提取待使用、已实际使用、已归还等         |
| 注册       | 未知、未注册、已注册；任务占用与结果确认分开       |
| 注册任务   | 排队、运行、完成、失败、取消、中断、待核对         |
| 注册后保存 | 本地保存、身份核对、主业务账号镜像同步分别记录     |

注册池只消费已登记、启用、主邮箱可用、查询码有效、确认未注册且无活动任务占用的子邮箱（S5:23-51、S6:17-77）。未知需先核对；已实际注册退出通用可提取库存，不能作为未使用归还。允许从十条中只归还未用的四条，阻止项不能被静默覆盖。

S7:561-565 的 `create_email()` 只返回已借用邮箱和 `aliasId`，S7:579-581 不删除该地址。S8:59-108 的主账号同步是注册账号镜像，受来源任务、身份及 fingerprint 校验，并非 Apple 隐藏地址同步。邮箱管理、账号管理、客户订单继续遵守既定独立边界。

录入人固定，最近修改／操作人按各自语义更新；导入、同步、测试、码重置、归属修复、注册、归还分别保留稳定人员编号及姓名快照。历史无依据显示“历史未记录”，公开查询标公开来源，不冒充后台管理员。见 [全表人员追溯规划](DATA_PROVENANCE_PLAN.md)。

## 6. 演示与正式边界

- 原型只用虚构主邮箱、子邮箱、查询码和邮件，在当前页面内存演示。连接、同步、查询不是真实 Apple／IMAP／Vendure 回执。
- 原型专用密码仅做演示输入校验，不连接服务，不把原文存入集合、草稿、日志或导出；禁止填真实秘密。
- 新模块与现有库存共用子邮箱编号、主邮箱编号和资料；既有提取、归还、注册及人员出处不得因换页签丢失。
- 正式接入复用 `/id-business-v2/vendure-mailboxes`、公开码查询及既有 Vendure 客户端，不造平行邮箱库、用户体系或资源池。服务端会话决定人员，响应元数据只读。
- 本轮不改线上互通配置，不执行真实收信、Apple 地址创建、注册、邮件归属修改、查询码重置、删除、数据库迁移或部署。老版继续使用，测试确认后由用户另行安排切换。

## 7. 兼容、迁移与后续验收

正式开发先核对远端主／子编号及数据，再分能力接界面；不能按邮箱文本重建所有身份。需要数据库能力时另列增量方案，不修改纯净基线或导入其他项目迁移。

1. 完整映射主／子编号、父子关系、状态、备注、查询码、有效期和同步资料；人员未知保持未知。
2. 保留收件 messageId、来源主邮箱、目标子邮箱及未分配记录；重复同步不新增重复邮件，不覆盖人工确认归属。
3. 原注册池、在途任务、身份检查、账号镜像、提取归还继续引用同一子邮箱，不重复注册或重复占用。
4. 公开查询与 Vendure 契约兼容；主／子码范围、到期、重置、旧码及跨邮箱隔离分别验证。
5. 远端受理而本地回执失败先回读原对象／批次，不能整批重复提交代替核对。旧功能退役与线上切换另行安排。

验收至少覆盖：主邮箱新增／编辑／专用密码留空，缺父／无效父阻止登记，搜索选父及编号确认；单条、批导重复与逐行统计；主子码范围／重置／到期；测试／同步失败与重复同步；查询主动同步、空结果、失败重试、同目标保留／换目标隔离；收件正文、未分配、同父重新分配、历史预览后确认修复与歧义阻止；已注册／未知／任务占用／无效码／不可用主邮箱的阻止；草稿、版本、人员防伪造与敏感原文不入日志；深浅主题、手机、完整列、列设置、分页首末页、空状态、真实文字对齐及44px／36px控件。

## 8. 本轮实际执行结果

当前修订 `20261104-apple-relay-21`，独立原型代码与本地页面验证完成。新增 `apple-relay-prototype.js`、专项测试及本文；库存通用入口、复制、删除引用保护、注册记录和导入历史已接到同一资料集合。静态预览仅白名单增加新脚本，未连接外部业务。

全部 189 项原型测试通过，其中隐藏邮箱专项 30 项；集成回归覆盖工作台转入、未知父级、提取资格确认时变化、普通表单绕过、批次回读、复制地址与查询码及删除保护。七项 UI／模块检查、定向语法、lint 和格式检查通过。未修改正式 Vue／NestJS 业务源码，未重复无关正式类型／构建。

实页验证新增主邮箱→登记隐藏邮箱→CSV 错误预检／整批导入→工作台回读；查询先同步、同目标失败保留、换目标清除、禁用父级阻止查询并减少可提取数量；历史归属先预览后确认修复、同父重新分配；隐藏邮箱提取、单条归还、注册待核对回读；邮件归属草稿与明确重新载入。主表与详情保留有效天数、批次、人员及状态，隐藏邮箱列设置默认 21 列，主邮箱 17 列。

页面覆盖六档宽度、深色手机与 44px 控件；首末页和空状态表格外框均为 451px，标签实际文字中心与首行控件中心差约 0.5px。证据保存在项目 `.runtime/redesign-apple-relay-20261104/`，不将原型模拟成功当作 Apple、IMAP、Vendure、注册器或真实邮件成功。

正式待完成：独立新版工作区与接口环境、共享 Vue 组件接入、旧远端主子编号及历史资料映射、真实权限／加密凭据／同步失败和幂等验证，以及注册任务消费适配。继续复用老接口，不新建平行外部邮箱库。本轮无正式接口、表、字段、migration、外部写入、提交、推送、PR 或部署，线上系统未变。
